# C13 MessageStatus 验收

日期：2026-11-20。

## 范围与实现

用户明确确认 C13 做成独立组件并加入调试台，调整了原计划的消息内部区域归属。在 `packages/ui` 提供 `@plotloom/ui/message-status`，未替换现有聊天页面实现。

- `status` 由调用方提供，支持等待响应、生成失败、已停止和 null；默认 48px 行高，null 隐藏内容但保留占位。
- 失败说明以纯文本显示，长文本省略，悬停或键盘聚焦查看全文，避免错误文案长度改变行高。
- 失败或停止且存在 `onRetry` 时提供重试；等待时不提供重试。复用 Button、Tooltip 与 Lucide 图标。
- 重试支持 Promise 等待、同步锁防重复、宿主忙碌和禁用；回调拒绝原位反馈并通知 `onRetryError`，回调完成不推断生成状态。
- 调试台「AI 对话组件」登记九个样例，公开状态、错误说明、回调可用性、重试处理中和禁用参数。

- 覆盖等待、失败、停止、隐藏、无回调、禁用、宿主忙碌、异步等待防重复、重试失败及再次重试、旧错误清理、长文案、纯文本、窄容器、减少动效、读屏语义与 Enter/Space 操作。
- 核对状态出现、消失、连续快速切换和重试反馈：状态行与按钮坐标和尺寸保持稳定（浮点容差 0.1px）。
- 键盘全文提示采用真实 Tab/Shift+Tab 导航验证；单纯程序设置焦点不会触发基础 Tooltip 的键盘可见焦点行为。
- 截图 `output/playwright/message-status-workbench.png` 已目视检查。

## 八条规则核对

1. 仅实现 C13 的状态与可选重试，不引入业务状态机或通用扩展框架。
2. 组件仅接收 props 和回调，不请求后端或依赖应用状态。
3. 状态控制、占位策略、异步锁和错误反馈有关键注释。
4. 独立组件归属已由用户明确确认后实施。
5. 新增组件，未替换旧接口或旧聊天实现。
6. 状态行无边框；复用无边框按钮和聚焦反馈，无嵌套描边。
7. 通用状态行、样式与调试样例由 `packages/ui` 维护。
8. 默认固定行高及操作占位，出现、消失和快速切换已验证无位移。

无公开业务接口变更，不涉及接口目录和接口试验台更新。真实聊天页面与重试业务协议尚未接入，未将其计为完成。
