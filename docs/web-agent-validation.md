# 正式前端侧边栏与基础 Agent 接入验收

日期：2026-11-18。

## 范围

- 复用 `packages/ui` 的 GlobalLayout、Sidebar、导航、分类、会话条目、按钮和滚动组件。
- “新聊天”固定；“技能、小说管理”位于滚动导航区；下方仅有“最近、小说”，小说使用 Book / BookOpen。
- 最近会话读取 `/api/chats` 并仅显示 `workspaceId === null` 的普通聊天。支持创建、读取历史、发送流式消息、停止、错误反馈及重新查询。
- 技能页读取 `/api/skills`；主题设置沿用原能力；小说页面仅占位。
- 全部数据通过已有公开 HTTP / SSE 契约访问，没有新增或修改后端业务接口、事件或接口目录。

## 项目规则核对

1. 只实现本轮基础能力；不添加小说业务、路由框架或通用状态框架。
2. 前端仅依赖公开契约，不引用 SDK、数据库或服务端内部包。
3. 新建、流解析、消息提交、停止、快照恢复和代理均有职责与原因注释。
4. 已明确本轮需接基础 Agent，不接小说业务。
5. 沿用现有后端接口及组件库能力；设置能力保留。
6. 新增页面使用背景和间距区分层级，输入聚焦使用无 border 的内阴影；仅技能列表使用中性单侧分隔线。
7. 通用能力来自组件库；应用页面与业务状态留在 `apps/web`。

## 运行

分别执行 `pnpm.cmd start` 和 `pnpm.cmd web`，访问本机 4319 端口。开发及 preview 默认代理到本机 4317，可通过 `PLOTLOOM_PORT` 或 `PLOTLOOM_WEB_API_TARGET` 指向其他本机后端。生产静态部署需将 `/api` 配置为同源后端代理。模型沿用后端已有配置；本轮未增加模型配置界面或技能编辑能力。
