# 工作区页面框架验收

2026-11-20。本阶段交付页面框架，不代表完整浏览器和文件能力已产品化。

## 实现

- 聊天页复用现有导航、聊天内容和 SplitPaneLayout，右侧以标签栏作为顶部框架。
- WorkspaceTabs 在 packages/ui 维护，共用标签、工具栏和独立滚动容器；每个业务页在 apps/web/workspace 就近组合。
- 支持新增、关闭、空态、键盘切换、标签溢出滚动、分栏调宽、收起重开与窄屏模态。
- 浏览器、Markdown、图片具有独立页面入口。浏览器保留地址草稿，但尚未连接原生宿主；文件页面尚未接入项目文件打开接口。不存在伪装网页或硬编码预览文件。
- 标签状态只在当前工作区挂载期间保存；刷新或离开聊天页后不持久化。接入真实资源时还需实现各页的资源释放和可见状态通知。

## 验证

- `pnpm.cmd typecheck`：通过。
- `pnpm.cmd test:ui`：29 项通过，包含所有公开组件目录覆盖。
- `pnpm.cmd web:build` 与 `pnpm.cmd ui:build`：通过，构建仍提示部分 chunk 超过 500 kB。
- `tests/ui/workspace-frame-browser.js`：18 项通过，验证三个独立页面、切换草稿保留、键盘导航、关闭邻页选择、快速切换布局稳定、宽窄切换与收起重开。
- `tests/ui/workspace-tabs-browser.js`：9 项通过，验证每页输入与滚动独立、Delete 焦点恢复、禁止关闭、溢出标签定位、空态新增。
- `tests/ui/split-pane-browser.js`：既有 32 项回归通过，默认标题栏、拖拽、窄屏及焦点行为不受可选头部槽影响。
- 桌面与窄屏截图已目视检查：`output/playwright/workspace-frame-desktop.png`、`workspace-frame-narrow.png`；调试台截图 `workspace-tabs-workbench.png`。

调试发现并修正：样例外层的 height:100% 被自动尺寸的 undefined 覆盖，导致长正文撑开画布。现将尺寸直接传给 WorkspaceTabs 根元素，恢复组件默认有界高度与真实独立滚动。

## 八条规则核对

1. 仅建设已批准的页面框架与三个内容入口，不扩展 Changes、编辑器或插件系统。
2. 组件和页面不访问后端内部、Pi、数据库或本机文件系统。
3. 标签生命周期、关闭选择、尺寸和边界处有职责及原因注释。
4. 按用户确认的布局与每标签独立能力实施。
5. SplitPaneLayout 只追加可选参数，保留现有默认行为；未删除旧接口。
6. 背景区分标签状态，单侧中性分隔线；控件不叠加完整边框与阴影。
7. 通用框架在 packages/ui，业务页面在 apps/web；调试台使用独立通用样例。
8. 固定工具栏和正文锚点，隐藏页保留状态，快速切换验收通过；重开入口预留标题栏空间。

本轮未新增或修改公开业务接口，接口试验台不产生新增登记。下一阶段接入浏览器宿主或文件能力时必须同步契约、catalog、试验台与独立 API 测试。
