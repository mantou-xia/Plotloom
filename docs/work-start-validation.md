# 工作初始页验收

日期：2026-11-19。

范围：用户确认「新聊天」为进入当前工作上下文初始状态的按钮，本轮不接通小说。沿用现有侧栏和公开接口。

## 交付行为

- 复用 AsciiOcean 鲨鱼鱼群背景和原版 TaskComposer；中央显示当前项目名称。按用户后续要求删除底部项目选择区域、参数和样式，底部仅保留对话框与必要加载/错误反馈，项目选择方式待讨论。
- 打开项目聊天后点击新聊天继承项目；切入普通聊天后新聊天不携带之前的项目。再次点击新聊天重置草稿。
- 打开初始页不创建空会话。首条发送、上传或项目引用按需创建；并发附件共用创建请求。会话绑定后目录固定。
- 首条消息 accepted 后进入既有聊天页，由服务端运行快照更新生成内容；初始页订阅断开不会停止后端生成。
- 创建失败保留输入；发送失败保留输入，重试复用已创建会话。模型列表失败支持重新加载，无模型时禁止发送。

## 验证

- `pnpm.cmd --filter @plotloom/web build`：类型检查和生产构建通过。构建仍提示主包超过 500 kB，本轮未扩展为打包优化任务。
- `pnpm.cmd test:ui`：24 项通过。
- `tests/ui/work-start-browser.js`：检查初始加载不建会话、背景复用、Windows 项目继承、底部无项目选择控件、发送失败保留输入、请求目录正确、重试复用会话、accepted 后进入记录、再次新聊天、普通聊天切换、创建失败保留输入、1024/768 像素窗口无横向溢出和无模型禁用。
- 浏览器流程拦截公开 HTTP/SSE 协议，用可控响应验证成功和失败；未调用真实模型生成，不将此结果宣称为真实模型验收。
- 页面截图位于 `output/playwright/work-start-project.png` 和 `work-start-narrow.png`；中央背景减弱对比以保持文字可读。

执行浏览器脚本：启动正式前端后使用 `npx.cmd --yes --package @playwright/cli playwright-cli -s=plotloom-start run-code --filename=tests/ui/work-start-browser.js`（需先 open 浏览器）。

## 七条规则核对

1. 只实现工作初始状态及现有项目上下文，不扩展小说管理。
2. 应用通过已有公开接口交互，不依赖后端内部实现或本机文件系统。
3. 会话创建去重、首条发送确认、页面切换和订阅清理均有职责与原因注释。
4. 已澄清页面含义和小说范围后实施。
5. 按用户明确要求删除项目选择区域及相关无效代码；不替换公开接口。
6. 新增页面样式不增加完整边框、彩色描边或边框与阴影叠加。TaskComposer 沿用此前确认的原版视觉。
7. 复用 packages/ui 组件；业务组合及状态均保留在 apps/web。

本轮无新增或修改公开业务接口，无需变更接口目录、试验台或 API 测试。仓库本轮无可用 `.cursor/rules/*.mdc` 及指定的 space 计划、记忆目录。
