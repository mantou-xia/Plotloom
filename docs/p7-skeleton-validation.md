# P7 前端骨架验证

日期：2026-11-18。范围仅为正式前端工程、feature 组织约定、项目组件库和两个布局组件；不代表 P7 产品功能或视觉体验完成。

## 交付内容

- `apps/web`：TypeScript + React + Vite，`src/app` 装配应用，`src/features` 按业务划分后续页面组合、状态与接口调用。
- `packages/ui`：统一维护组件和组件样式，通过 workspace 导出供应用使用；新增组件前先复用已有能力。
- `GlobalLayout`：左侧 `aside`、右侧唯一 `main`；侧栏暂用 16rem 结构占位，尚未确定视觉方案。
- `PageLayout`：在 `main` 内承载一级页面，只接受 children；不定义样式。
- `AGENTS.md`：新增第七条铁律，禁止在页面或 feature 内单独维护组件或复制已有实现。

当前页面留空，没有业务内容、导航项、接口调用、路由或状态管理框架。新增前端不依赖服务端内部包。

## 七条规则核对

1. 不过度设计：只实现两个当前需要的布局；其他模块随实际需求创建。
2. 前后端解耦：前端和组件库没有后端内部依赖，目前没有接口调用。
3. 清晰注释：应用装配、React 入口和布局组件标注职责；结构样式说明占位原因。
4. 需求明确：按用户指定范围交付骨架，一级页面视觉方案留待后续讨论。
5. 旧实现处理：新增正式产品前端，没有替换或删除现有接口试验台与业务接口。
6. 边框层级：未增加 border、box-shadow 或 outline。
7. 统一组件维护：两个布局都位于组件库，应用仅导入和组合；规则及目录约定已同步。

本次没有新增或修改公开业务接口，因此无新增接口登记、接口试验台交互或真实模型验收项；未重跑完整后端接口套件。后续具体页面、真实接口接入、交互及视觉体验继续按 P7 验收。
