# AgentActivityHeader 组件验收

日期：2026-11-20。范围：组件库及调试台，不含真实思维链组件、聊天或后端阶段信号。

## 功能

- 固定高度的独立粒子区与右侧九宫格动画图标、状态、耗时；默认 360px，思考期间没有收起入口。
- 右下方 children 仅作为插槽；Header 不再导入 ScrollBox，不管理内容滚动或展开，旧展开参数及完整展开按钮已清理。
- 明确进入 answering 或 completed 时隐藏整个视觉 Header，释放 Canvas；保留同一插槽 DOM。
- 调试台占位内容自行组合 ScrollBox 和折叠按钮；结束自动收起内容，手动展开不恢复 Header，后续回答增量和 completed 不覆盖展开选择。
- 水平拖动和方向键旋转实体，Home 复位；按实际画布缩放换算距离，指针取消、失去捕获及卸载清理交互。
- 失败和停止原位更新标题，保留内容与尺寸，停止粒子运动。
- 文案和形态可独立覆盖；提供阅读、编写、修改、搜索、浏览、执行、思考、处理预设；未知工具兜底仅在示例映射演示。
- 新任务通过 key 重建；耗时完全由调用方提供，不传则不显示。
- 窄于 540px 的组件容器上下排列，保留右侧思考区高度与内部滚动。
- Canvas 在 Header 隐藏时卸载，在离屏、页面隐藏、停止、系统或显式减少动态效果时停止 RAF；组件卸载清理监听与观察器。减少动态效果关闭图标动画，但仍允许用户主动旋转视角。

## 八条规则逐项核对

1. 只做确认的组件范围，无模型摘要服务、工具注册框架或额外后端能力。
2. 通过 props/children/回调交互，不依赖 SDK、业务状态或接口内部实现。
3. Header 隐藏、指针生命周期、示例内容折叠等关键逻辑已有注释。
4. 用户已确认内容插槽边界，并明确纠正结束后 Header 隐藏、只展开内容。
5. 用户已授权清理旧展开参数；无兼容死分支，不改旧聊天实现。
6. 组件无完整边框嵌套、彩色描边或边框叠阴影；复用统一按钮焦点样式。
7. 组件与样式在 packages/ui；调试台展示公开参数与占位内容，未封装业务页面。
8. 活动文案、形态、失败和停止保持高度；耗时锚定右侧避免长文案挤动。结束隐藏 Header 及内容展开是用户明确要求的布局变化。

本轮无公开接口变更，接口试验台登记要求不适用。真实工具映射、最终回答阶段识别及聊天页面接入仍待后续实施，不能据此宣称已接通后端。
