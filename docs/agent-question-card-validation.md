# Agent 选择题卡片验收

2026-11-21。项目聊天和小说聊天都可以通过 `ask_user` 发出一道单选题。等待时原轮次继续持有会话锁，活动、执行过程和侧栏显示待回答状态。选择、自填和跳过均提交给原轮次。停止任务会取消等待。待回答问题随正在运行的服务进程保留，页面刷新后可恢复。

## 验证

- 独立 HTTP/SSE 测试通过。覆盖单选、自填、跳过、停止、会话忙、空白答案、超范围选项、跨会话提交、重复提交和停止后提交。确认答复进入模型后续请求和对应轮次的工具历史。
- Edge 正式聊天页实测，覆盖输入框原位切换、问题刷新恢复、侧栏和活动状态、快速切换自填和单选、提交、跳过与停止。输入区位置和尺寸保持稳定。截图见 `output/playwright/agent-question-card.png`。
- Edge 接口试验台实测，覆盖 SSE 和详情自动填入问题 ID、成功回答、错误参数、重复提交及等待时停止。浏览器与 HTTP 验证使用确定性模型协议替身。
- `pnpm test` 99 项、`pnpm test:demo` 16 项、`pnpm test:ui` 29 项通过。类型检查、网页构建和试验台构建通过。

## 项目规则核对

1. 每个会话一次只处理一道待回答问题，与现有生成锁一致。
2. 聊天页和试验台通过公开 HTTP/SSE 访问，接口可独立运行。
3. 等待、取消、一次性提交和草稿保留的关键逻辑均有注释。
4. 已确认单选、自填、跳过和关闭按钮的交互。
5. 回答接口独立新增，沿用现有消息发送、审批和停止接口。
6. 卡片使用背景色区分层级。选项通过背景和编号标记选择，聚焦不改变占位。
7. 通用卡片放在 `packages/ui`，并在组件调试台登记公开参数和状态。业务请求在聊天页发出。
8. 卡片覆盖原输入区占位，提交和停止反馈使用原控件尺寸。
