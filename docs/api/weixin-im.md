# 微信 IM 通用能力

日期：2026-11-24。使用腾讯公开 iLink 协议，本机后端发起 HTTPS 长轮询，无需公网回调地址。服务器或桌面应用必须保持运行且可访问微信；电脑关机或应用退出后不能收发。

微信通道提供本人文字对话与主动文字通知。全局接入可以在同一微信聊天中切换平台已登记的小说或项目。固定接入沿用一个已有对话。

## 使用流程

产品入口为「设置 → 手机接入」。点击「扫码连接」，默认选中「全局接入」，可直接获取二维码。弹窗会自动查询扫码结果，微信需要 PIN 时可在弹窗中提交。已有固定连接可点击「切换为全局接入」，沿用微信授权，原会话继续在平台保留。

全局接入后可以直接发消息，首条普通消息自动开启无工作区对话。普通聊天与小说、项目各自保存历史，可发送「回到普通聊天」续聊。发送「可聊什么」查看目标。「跟我讨论《归潮》的后续剧情」会切到该小说并回答。「切到项目《远灯》」只切换当前目标，之后省略名称即可继续。同名目标要加「小说」或「项目」区分。需要用不同名称区分同类型的重名目标。

所有微信模型回复使用「设置 → Agent 人设」的名称、语气和偏好，并附加微信呈现规则，例如长内容分段、说清确认方式。固定操作和错误提示带已设置的人设名称，保留准确状态及操作指令。

每个连接可单独设置自动新起会话。默认关闭，开启时为 6 小时，可改为 1–168 小时。达到空闲时长后，下一条普通微信消息开启当前目标下的新对话。各目标分别计时，旧聊天保留，微信授权继续有效。停止和审批继续作用于当前会话，等待回答时先处理当前问题再切换目标。

以下步骤用于接口试验台验证。

1. 启动后端与接口试验台：`pnpm.cmd start`、`pnpm.cmd demo`。模型配置沿用项目原有方式。
2. 在试验台搜索“微信”，打开“获取微信绑定二维码”，选择“扫码全局接入”发送。若验证固定接入，选择“绑定固定会话”并填入已有的 `sessionId`。
3. 确认响应中 `mode` 与本次选择一致。全局接入的初始 `sessionId` 为 `null`。
4. 用本人微信扫描结果末尾的二维码。打开“查询扫码状态或提交 PIN”，`loginId` 已自动带入，提交 `{}`；每次请求最多等待约 35 秒。
5. `waiting` 或 `scanned` 时继续查询；`pin_required` 时提交手机要求的数字，如 `{"pin":"001234"}`；`expired` 时重新获取二维码。PIN 不保存到磁盘。
6. `confirmed` 返回 `accountId` 并启动接收；该 ID 自动带入后续接口。`already_bound` 表示微信没有签发新凭据，检查本机已有连接列表，不把它当作新绑定成功。
7. 在微信发送文字。最终答复通过微信返回，同一会话的用户消息和模型答复也能在平台查看。文件变更预览在生成结束后发送，用户通过下一条微信消息确认。
8. 使用“主动发送微信文字”提交固定 `requestId` 和文字，随后查看“最近收发结果”。

默认试验台地址为 `http://127.0.0.1:4318`。独立 worktree 验收时可用 `PLOTLOOM_DEMO_API_TARGET` 指向另一个本机后端，Vite `--port` 指定不冲突的端口。

## 公开接口

全部接口从 `packages/contracts/src/catalog.ts` 注册，试验台完整展示字段、请求和错误。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/api/im/weixin/logins` | `{mode:"global"}` 全局扫码，或 `{sessionId}` 固定扫码 |
| POST | `/api/im/weixin/logins/:loginId/poll` | `{}` 查询或 `{pin}` 提交手机数字 |
| GET | `/api/im/weixin/accounts` | 列出连接、绑定、活动状态及错误 |
| PUT | `/api/im/weixin/accounts/:accountId` | `{enabled}` 启停、`{mode:"global"}` 切换全局、`{sessionId}` 固定改绑、`{idleSessionHours}` 设置空闲时长 |
| DELETE | `/api/im/weixin/accounts/:accountId` | 清除本机凭据和通道记录，保留 Agent 会话 |
| GET | `/api/im/weixin/accounts/:accountId/messages` | 查询最近 100 条收发记录 |
| POST | `/api/im/weixin/accounts/:accountId/messages` | 主动发文字，返回发送记录 |

主动发送示例：

```http
POST /api/im/weixin/accounts/<accountId>/messages
Content-Type: application/json

{"requestId":"budget-warning-20261124-1","text":"Plotloom 主动触达测试。"}
```

`requestId` 为同一连接下的幂等键，允许 1–120 个字母、数字、下划线或短横线。文字最多 4000 UTF-8 字节。内部 Agent 长答复按 4000 字节切块，保留中文和 emoji，每块独立记录；某块失败或结果不明后不继续发送剩余块。

## 微信内操作

| 输入 | 行为 |
| --- | --- |
| 普通文字 | 会话空闲时交给 Agent；等待选择题时作为自填答案 |
| `选项 2` | 回答当前选择题的第二项 |
| `跳过` | 跳过当前选择题 |
| `批准` / `拒绝` | 执行或取消本连接当前会话里已发出预览的文件变更 |
| `停止` / `/stop` | 停止当前生成或取消待确认文件变更 |

微信每轮最多暂存一项通用文件变更。预览发出时会话已经空闲，批准只提交该份变更一次，拒绝不写入。写入前重新检查原文件和目录，如果已变化，请重新提出修改以取得新预览。停用、改绑或服务重启时待确认变更失效。网页继续实时审批，小说等专项操作如需独立确认，需在网页发起。

会话忙时不自动排队：明确回复忙碌，入站记录为 `failed/SESSION_BUSY`。图片、语音等回复当前仅支持文字，不进入模型。只接收扫码者本人且目标 bot 匹配的私聊；其他用户和群消息不分发。一个会话最多绑定一个微信连接。

## 主动触达的结果口径

主动接口不依赖新入站消息，也不等待 Agent 生成。优先携带最近的本人入站 `context_token`；没有该令牌仍尝试发送，最终是否接受由微信服务端决定。

| 出站状态 | 含义与处理 |
| --- | --- |
| `sending` | 已持久化，正在请求微信；重复调用返回同一记录 |
| `accepted` | 微信接口接受；没有手机送达或已读回执 |
| `rejected` | 明确被拒绝或尚未发出；查看 `error` |
| `unknown` | 超时、连接中断、无效响应或进程强退，无法判断是否已被微信接受；不自动重发 |

HTTP 200 表示存在发送记录，不代表发送成功。试验台额外检查 `status === accepted`，拒绝和结果不明显示检查未通过。相同 `requestId` 和文字永远返回原记录；换文字返回 409。需要重试时先核查微信和记录，再由调用方明确选择新幂等键，不能通过不断换键规避防重发。

平台可调用此接口触发业务通知，但本阶段不承诺任意时段无限制主动触达。真人实际微信接受条件、时间窗口和终端到达以实测为准；不能从协议替身成功推断这些限制。

## 持久化、停用与错误

- 凭据、上下文和收发记录保存在数据目录 `im/weixin.json`；原子写入，游标和入站记录同次提交。机器人 token、上下文 token 和游标从不进入公开响应或错误日志。数据目录仅供一个后端进程使用。
- 入站先落盘，再调用 Agent。重启把 `received/processing` 标为 `interrupted`，保留去重标识，不自动再次执行可能已有副作用的业务；用户可检查会话后明确重试。
- 停用、改绑、删除先取消轮询和本连接发起的运行、发送，等待完成后再更新绑定。微信里点停止可停止同一会话由平台发起的生成。
- `-14` 或认证拒绝标记 `login_required`，不持续重试无效凭据；需重新扫码。普通轮询网络错误显示 `error`，以短间隔重连。二维码凭据仅在内存中存在，重启需重新获取。
- 删除本机连接不等于撤销微信端授权；微信端授权在微信插件管理中处理。Agent 会话内容不随通道删除。
- 公开服务沿用本机同源限制和桌面令牌校验，不能直接作为公网多租户 API 部署。
