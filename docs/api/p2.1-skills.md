# P2.1 技能管理与小说聊天接口

日期：2026-11-18。已实现并通过独立接口与试验台验收，见 [验收记录](../p2.1-validation.md)。以下路径均位于本机服务；字段、可编辑示例和错误也登记在 `packages/contracts/src/skill-catalog.ts`，由主 catalog 汇总。

## 1. 接口目录

| 方法与路径 | 输入 | 返回与用途 |
| --- | --- | --- |
| GET /api/skills | 无 | `{skills: SkillInfo[]}`，应用技能库 |
| POST /api/skills | `{content}` | 201 SkillInfo，新建含 YAML frontmatter 的 SKILL.md |
| POST /api/skills/import | `{root}` | 201 SkillInfo，复制本机完整技能目录 |
| GET /api/skills/:skillId | 路径 ID | SkillInfo，详情及依赖诊断 |
| POST /api/skills/:skillId/file | `{path}` | SkillFile，读取技能内资源 |
| PUT /api/skills/:skillId/file | `{path, content, baseVersion}` | SkillInfo，新建或更新 UTF-8 资源 |
| POST /api/skills/:skillId/copy | `{name}` | 201 SkillInfo，连同资源复制为自定义技能 |
| DELETE /api/skills/:skillId | 路径 ID | `{deleted:true}`，移除非内置技能 |
| GET /api/workspaces/:workspaceId/skills | 工作区 ID | `{skillIds}`，工作区默认启用列表 |
| PUT /api/workspaces/:workspaceId/skills | `{skillIds:string[]}` | `{skillIds}`，完整替换默认列表 |
| GET /api/sessions/:id/skills | 会话 ID | SkillActivation，下一轮配置及不可用原因 |
| PUT /api/sessions/:id/skills | `{skillIds:string[]\|null}` | SkillActivation，覆盖或恢复跟随 |
| GET /api/chats | 无 | `{sessions:ChatSummary[]}`，按更新时间倒序且带工作区归属 |
| GET /api/workspaces/:workspaceId/sessions | 工作区 ID | `{sessions:ChatSummary[]}`，该小说的聊天 |
| POST /api/workspaces/:workspaceId/sessions | 可选 name/provider/model/thinkingLevel | 201 会话摘要和 workspaceId，创建固定归属的聊天 |

消息接口 `POST /api/sessions/:id/messages` 新增可选 `skillIds:string[]`，表示本轮明确加载这些已启用技能的 SKILL.md。省略时仍可由模型按任务选择；它不修改启用配置，也不临时启用其他技能。请求/停止/流式协议沿用 [P1](p1-agent.md)，结束仍为 completed、failed 或 aborted。

## 2. 公开数据

SkillInfo 包含 `id/name/description/version`、`source`（builtin/custom/imported）、`origin`（来源说明或导入路径）、`updatedAt`、`files`（相对路径列表）、`compatibility`（原环境说明）、`declaredTools`、`missingTools`、`warnings` 和 `runnable`。版本是整个文件包的内容哈希；更新必须使用读回的版本，不能填固定值。

`runnable` 仅表示已声明工具在本服务可用，不证明所有自然语言依赖或运行环境满足。compatibility 需人工核对；scripts 文件始终不执行。内置 novel-writing 已安装并作为小说默认技能，但依赖的资料/候选工具尚待 P3，因此当前显示缺少工具且不会装入模型；纯方法或仅依赖 read_skill 的自定义技能可使用。

SkillFile 为 `{path,content,encoding,version}`；UTF-8 文件的 encoding 为 utf8，其他内容返回 base64。资源编辑只接收文本，单次最多 500000 个字符；二进制通过完整目录导入保留。内置资源只读，调整时先复制。

SkillActivation 包含 `workspaceId`、原始 `skillIds`、`mode`（inherit/override）、`effectiveSkillIds`、详情 `skills` 和 `{id,reason}[]` 形式的 `unavailable`。删除技能会清理工作区默认引用，聊天覆盖保留已删 ID 并明确报告不可用，以免静默改变用户选择。

ChatSummary 在原会话列表项上新增 `workspaceId:string|null`。普通会话归属为 null；小说聊天在创建时写入 SDK 自定义元数据，导航不会改变归属。本阶段没有迁移聊天接口。

## 3. 启用与本轮加载

| 设置 | 行为 |
| --- | --- |
| 工作区尚未设置 | 默认 builtin-novel-writing |
| 工作区 skillIds 为数组 | 完整替换默认值；空数组关闭全部 |
| 聊天 skillIds 为 null | 跟随所属工作区；普通聊天默认无技能 |
| 聊天 skillIds 为数组 | 完整覆盖工作区；空数组关闭全部 |
| 消息 skillIds 为数组 | 仅对本轮已启用、可运行技能立即加载入口正文 |

设置、编辑、删除均从下一条消息生效。接受消息时固定技能版本及 UTF-8 资源到内存；运行中的 read_skill 读取该快照，之后管理操作不会使本轮读到混合版本。历史聊天不会因为停用而遗忘已读取文本，但下一轮不再获得被停用资源的读取权限。

技能摘要进入系统提示，模型用 `read_skill({skillId,path})` 按需读取入口或参考。仅允许本轮快照中的精确相对路径；不提供通用 read/bash 或外部脚本执行。已有会话的工具查询显示当前 SDK 实例，设置改变后在下一条消息装配时刷新；查看下一轮技能配置应使用 `/sessions/:id/skills`。

## 4. 调用示例

新建技能：

```json
{"content":"---\nname: dialogue-guide\ndescription: 打磨人物对白\nallowed-tools: read_skill\n---\n依据人物身份检查措辞差异，保留作者意图。"}
```

将返回的 ID 用于小说默认设置，再通过小说入口创建聊天：

```text
PUT /api/workspaces/<workspaceId>/skills
{"skillIds":["<skillId>"]}

POST /api/workspaces/<workspaceId>/sessions
{"name":"对白讨论"}

POST /api/sessions/<sessionId>/messages
{"text":"请按这份技能讨论下面的对白……","skillIds":["<skillId>"]}

PUT /api/sessions/<sessionId>/skills
{"skillIds":null}
```

目录导入示例：`{"root":"D:/skills/dialogue-guide"}`。该目录须包含 `SKILL.md`，frontmatter 的 name 与目录名一致；name 为最多 64 字符的小写英文、数字及单连字符，description 最多 1024 字符且不能为空。支持 YAML 多行数据，拒绝无效元信息。复制会更新 name 并保留全部资源。

## 5. 存储与错误

导入复制普通文件树，保留 references/assets/scripts；最多 500 文件、20 MiB，拒绝链接、目录联接、越界、Windows 路径别名及大小写冲突。导入后原目录变化不影响安装副本；同名技能不会静默覆盖。空目录不作为技能资源保存。

安装文件位于 `<dataDir>/skills/packages/<skillId>/<version>/<name>/`，清单位于 `<dataDir>/skills/state.json`。版本文件只创建，不覆盖；完整写入并核验后原子更新清单作为发布点，避免 Windows 新目录重命名的 EPERM。请求读取旧版本到内存后独立运行。不要直接编辑安装目录；应用外变更返回版本冲突。此机制不承诺断电事务或完整应用备份，P2 资产备份也不包含技能和聊天。

小说归属与聊天技能覆盖保存在 Pi JSONL 的 `plotloom-session-skills` 自定义条目中，不另存消息副本；重启后空聊天、归属、设置和历史仍可查询。

| 状态 / 错误码 | 含义 |
| --- | --- |
| 400 INVALID_REQUEST | 参数、YAML、相对路径、目录结构或大小限制无效 |
| 404 SKILL_NOT_FOUND / SKILL_FILE_NOT_FOUND | 技能或资源不存在 |
| 409 SKILL_NAME_EXISTS | 同名技能已安装 |
| 409 SKILL_READ_ONLY | 尝试修改或删除内置技能 |
| 409 SKILL_VERSION_CONFLICT | 编辑版本过期或安装文件被应用外修改 |
| 422 SKILL_IMPORT_FAILED | 目录不存在或无法读取 |
| 422 SKILL_UNAVAILABLE | 消息明确指定了未启用、已删或缺少工具的技能 |
| 500 SKILL_STATE_INVALID | 内部清单格式无效，需要检查数据与备份 |

会话/工作区不存在、生成忙、凭据缺失等错误沿用原接口。在线下载、压缩包解包、环境安装、自定义工具执行和 P3 小说创作工具不在本阶段范围。
