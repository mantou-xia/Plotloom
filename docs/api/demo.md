# 接口测试 Demo

日期：2026-11-17。独立的开发调试页面，源码位于 `apps/api-demo`，通过公开 HTTP / SSE 接口访问 P1 后端。

## 启动

1. 在根目录执行 `pnpm.cmd install --frozen-lockfile`。
2. 按根目录 README 配置 `.env`，执行 `pnpm.cmd start` 启动后端。
3. 另开终端执行 `pnpm.cmd demo`，打开 `http://127.0.0.1:4318`。

默认代理到 `http://127.0.0.1:4317`。后端端口可由根 `.env` 的 `PLOTLOOM_PORT` 指定；单独指定代理目标使用 `PLOTLOOM_DEMO_API_TARGET`，仅支持本机 HTTP 地址。修改配置后重启 Demo。模型凭据只由后端读取，不放入浏览器。

生产构建：`pnpm.cmd demo:build`；本机构建预览：`pnpm.cmd demo:preview`。开发与预览共用 4318 端口，同一时间选择一种启动方式，后端需要独立运行。

## 页面操作

- 从目录选择接口，可按名称、路径、方法或模块搜索。
- 先检查模型配置，再创建会话；会话 ID 自动填入，也可粘贴 ID 或选择已有会话。
- 编辑 JSON 或选择参数示例，点击“发送请求”。切换接口时保留本页内的参数草稿、示例选择和结果；刷新会清空这些状态，会话 ID 在当前浏览器标签页内保留。
- 右侧显示 HTTP 状态、耗时、实际路径、响应检查、原始数据和响应头，可复制结果。
- 模型选择器和思考档位选择器按公开能力编辑 JSON，点击发送才生效；会话列表显示名称、模型、档位和活动状态。
- SSE 正文和模型思考独立累加展示，工具、重试、压缩和结束事件进入时间线；原始数据可查看每个增量。详情页分开显示历史正文和思考；模型没返回时明确提示，不生成占位思考。
- “停止本次生成”调用停止接口；“断开订阅”只关闭浏览器连接，后端可能继续，可重新查询会话或停止生成。
- 手动压缩允许较长等待，执行中可点击“取消本次压缩”。断开订阅只关闭请求，后端压缩仍可能继续；取消完成显示“已停止”。内容不足的 409 显示为明确错误。

检查通过表示状态、公开字段及事件顺序满足当前检查项，不代表生成内容质量已验收。HTTP 200 中的 failed 事件仍标为失败；主动停止显示“已停止”；缺少最终事件或主动断订阅不会标为完成。页面未连接时展示后端启动提示。

## 扩展与边界

统一目录在 `packages/contracts/src/catalog.ts`。后续所有新增或修改接口必须登记所属模块、方法、路径、用途、字段和示例，页面自动生成目录和说明。新业务需要特别检查时，再扩展 `apps/api-demo/src/client.ts` 的实际检查逻辑。必须从试验台实际触发接口并核对结果，同时通过独立接口测试；未登记或未验证不能交付，具体要求见根目录 `AGENTS.md`。

目录覆盖测试递归核对 routes 下全部 TypeScript 路由文件、各 HTTP 方法及真实注册，防止只检查旧文件漏掉新增接口；响应示例也参与字段检查。该 Demo 不提供小说编辑器、不读取 SDK JSONL、不保存第二份会话历史；产品前端仍由 P7 实施。

## 六条规则核对

| 规则 | 核对结果 |
| --- | --- |
| 不过度设计 | 仅实现接口目录、说明、请求与结果检查，未增加前端框架或业务模块 |
| 前后端完全解耦 | 页面只依赖公开契约和 HTTP / SSE；后端可独立运行 |
| 关键函数有注释 | 目录渲染、请求状态、流解析、输出转义、代理边界均注明职责或原因 |
| 需求冲突先澄清 | 按用户明确提出的独立测试 Demo 实施，P7 产品范围不变 |
| 替换旧接口先确认 | 新增调用页面，未替换旧接口或旧后端实现 |
| 边框与层级 | 容器使用背景差异与间距，分隔用单侧中性边框，焦点阴影不叠加完整边框 |
