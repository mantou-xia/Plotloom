# Agent 状态与过程展示区实施计划

日期：2026-11-20。状态：按用户最新确认调整 Header 边界；真实思维链组件与聊天接入待后续实施。

## 已确认范围

- 只交付 `packages/ui` 通用组件与组件调试台；本轮不改聊天页面、后端或公开协议。
- 左侧粒子与右侧九宫格动画图标、活动文案、耗时属于 Header，运行时高度固定。
- 右下方保留内容插槽，滚动与具体内容由调用方组合；清理旧内容展开参数。
- 工作中不可收起；进入最终回答后整个视觉 Header 隐藏，不是折叠为摘要行。
- 结束后只对思维链内容展开收起；调试台先演示占位内容，展开不重新显示 Header。
- 粒子保留独立动效，增加水平拖动、方向键旋转与 Home 复位。
- 最终回答阶段不能由首个 text_delta 推断。真实阶段识别留待聊天接入。
- 活动文案和形态可传入，提供活动预设；工具名映射只在调试样例演示，业务映射以后放 apps/web。
- 耗时仅展示调用方提供的数据；通用组件不捏造计时或思考内容。

## 实施顺序

1. 参考 LeiBox thinking-particles 的深度光栅、黑白粒子和形态过渡，提取为外部状态驱动的独立渲染器。保留来源及原始文件，不接入演示计时剧情。
2. Header 根据公开 phase 隐藏视觉元素，保留同一 children；不维护展开状态。调试台用 Button 与 ScrollBox 演示调用方职责。
3. 调试台提供阅读、编写、搜索、执行、未知工具、长内容、最终回答、失败、停止与过程切换；允许编辑公开参数。
4. 检查类型、构建、UI 目录覆盖；浏览器验证拖动、图标、工作中不可收起、结束隐藏、内容独立展开、键盘、新任务、快速切换、窄屏及减少动态效果。
