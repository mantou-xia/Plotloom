# C10 CitationMarker 验收

日期：2026-11-20。范围：引用标记组件、独立调试台与公开参数；真实聊天页面、Markdown 引用解析和 C11 来源列表留待后续实现。

## 实现与决策

从 `@plotloom/ui/citation-marker` 导入 `CitationMarker`。

| 参数 | 含义 |
| --- | --- |
| index | 必填，从 1 开始的来源显示编号，调用方维护编号与来源对应关系 |
| sourceTitle | 必填，完整来源名称；用于可访问名称和提示层 |
| onActivate | 必填，打开或定位对应来源的回调 |
| active | 默认 false，标识当前来源，颜色变化并设置 aria-current |
| disabled | 默认 false，保留显示，阻止交互 |
| className / style | 作用于真实编号按钮 |

- 复用 Button 和 Tooltip，沿用键盘、聚焦与视口避让能力；新增内容只有引用的尺寸、语义和公开参数。
- 正文只显示紧凑编号，来源名称通过浮层呈现，因为长来源名不应挤动文字。
- 点击行为通过回调交给调用方，避免绑定 C11、业务接口或页面结构。
- 没有扫描或替换原文中的数字，也不自动猜测引用来源；用户提供的来源名称作为纯文本展示。
- 调试台提供单个引用、连续引用、当前来源、不可用来源、长名称与多位编号五个状态。可调整编号、来源名称、选中、禁用和尺寸；来源回调示例组合现有 Dialog，不代表完成 C11。

## 八条规则核对

1. 仅实现 C10 的显示与入口，不引入来源请求、自动引用解析或 C11 列表。
2. 所有数据和操作由 props 与回调提供，无业务或后端内部依赖。
3. 编号约束、来源责任边界和布局稳定原因均有注释。
4. 按既有计划 C10 范围实施；来源展示由调用方组合。
5. 新增能力，不替换或删除旧业务接口、聊天页面。
6. 编号用中性背景，无完整边框，聚焦复用 Button 阴影；选中颜色不用于描边。
7. 通用组件及样式位于 packages/ui；复用 Button、Tooltip，调试台组合 Dialog。
8. 提示不占文档流，选中只改变颜色，快速切换实测布局稳定。

未新增或修改公开业务接口，接口试验台要求不适用。
