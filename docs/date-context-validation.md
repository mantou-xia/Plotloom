# Agent 当前日期与缓存验收

日期：2026-11-20。

## 实现与缓存边界

- 每轮执行时从后端系统时钟读取当前日期、星期和本机 IANA 时区，以内部标记附在本轮模型输入末尾。普通聊天、项目聊天、小说创作与重试共用入口。
- 系统提示词、工具定义和已发送的历史不因日期更新而改写；不用秒级时间，不增加取时间的工具请求。日内日期文本稳定，跨天时仅新输入携带新日期。
- 日期与用户输入保存为同一条 SDK 消息，避免独立 custom 消息改变压缩轮次切分、额外产生摘要调用。原有自动压缩用量断言 `120020` 保持不变并通过。
- 公开历史从请求快照恢复用户原文；附件、引用、消息 ID 和重试目标保持原有契约。日期后缀不显示为用户正文。
- 每轮新增少量输入 token。缓存仍受供应商的保留时长、长度阈值、路由及上下文压缩影响，不承诺每次命中或固定命中率。本机时区用于本机应用，不推断远程用户时区。

## 项目八条规则核对

1. 不过度设计：只追加本轮日期，不新增时间服务、配置接口或联网搜索。
2. 前后端解耦：时间来自后端；前端继续使用既有公开协议。
3. 注释：日期格式、缓存前缀、压缩轮次和公开历史恢复均有原因说明。
4. 需求清晰：按已授权的日期修复与缓存约束执行。
5. 旧实现：未删除或替换公开接口；已有历史继续可读。
6. 边框层级：无前端样式变更。
7. 组件归属：无组件变更。
8. 布局稳定：内部日期不进入公开用户正文，无新增状态反馈或布局变更。
