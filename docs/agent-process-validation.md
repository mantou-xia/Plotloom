# C04～C06 Agent 过程验收

日期：2026-11-20。

## 交付范围

- C04 `ThinkingContent` 展示单段公开思考或摘要，无独立滚动和整体折叠。旧 ThinkingPanel 已按用户确认移除，导出、样例、控制字段及浏览器脚本已迁移，不保留兼容分支。
- C05 `ExecutionTimeline` 按调用方给定顺序展示 thinking、message、tool、event；稳定 id 原位更新工具输入、结果、状态。事件可表达步骤、重试、上下文整理、失败或停止，不按类型聚合。
- C06 `ToolCallItem` 展示工具名、摘要、四种状态、原文输入与结果；默认收起，完成/失败不自动展开，空结果与缺失结果有区别。长结果自然撑高。
- 整体统一定高阅读、展开全部、回到最新、上翻或查看详情时暂停跟随，首次最终回答时自动折叠一次。后续增量、停止、失败、完成保留手动选择。
- C03 插槽组合整个执行过程；最终回答仍在外部。模拟工具过程实际追加节点并原位更新上一个工具，支持重建新任务。
- 调试台分别提供 C04 四个、C05 十个、C06 七个独立样例，公开数据与参数可调。参考用户给出的 ThoughtChain 纵向节点与可展开详情；复用本项目组件，未添加 Ant Design X 依赖。

## 八条规则核对

1. 仅实现已确认 C04～C06 联合开发、C03 示例组合与必要文档测试，无额外业务框架。
2. 组件只接收公开展示 props，不请求后端、不依赖应用状态、Pi SDK、数据库或本机文件。
3. 排序职责、稳定 id、状态更新、自动折叠、跟随暂停、原文展示及演示事件均有关键注释。
4. 联合范围、全部可见过程信息和最终回答区外展示已由用户确认。
5. 用户明确批准旧 ThinkingPanel 无需保留；实现和入口已清理，历史文档明确标记取代。
6. 中性灰实线连接节点；无完整边框套嵌或层级阴影，详情使用背景与间距，按钮焦点复用组件库规范。
7. 通用组件和样式集中在 `packages/ui`，三个组件均独立导出并登记调试台；未抽取业务页面。
8. 状态图标、文字及工具栏入口固定占位，反馈出现、消失及快速切换均已验证；未通过动画掩盖位移。

本轮没有新增或修改公开业务接口，接口试验台要求不适用。以上浏览器数据均为本地模拟，真实聊天接入仍未实施；后续需补齐明确最终回答阶段和完整工具详情等公开契约，并完成接口试验台及独立接口验证。组件不会从首段正文推断最终回答，也不会擅自把未结束的工具标为成功。
