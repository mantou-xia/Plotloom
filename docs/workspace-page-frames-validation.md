# Markdown 阅读器与浏览器框架验收

日期：2026-11-20。范围：前端页面框架与交互契约，不含后端文件接口或原生浏览器连接。

## 已交付

- WorkspaceTabs 新增完整 page 插槽。自定义页面拥有自己的工具栏、内容和底栏，外层不额外添加工具栏或滚动容器；原 toolbar/content 用法继续可用。
- MarkdownReaderFrame：文件名/路径、打开回调、只读 Markdown、统一 ScrollBox、加载/失败/未打开/空文件状态和重试回调。已有正文在加载与错误时保留。
- BrowserFrame：地址草稿、受控网址、前进后退、刷新/停止、内容承载插槽、连接/错误状态。框架仅发出回调，不访问网络或创建 iframe。
- 两个框架支持自定义 toolbar、额外 actions 和根节点尺寸参数。业务页在 apps/web 组合，通用框架在 packages/ui。
- 调试台提供阅读器 7 个样例、浏览器 6 个样例；WorkspaceTabs 新增第 5 个完整自定义页面样例。

## 八条规则核对

1. 只建设已请求的两个框架，不增加编辑器、插件系统或业务后端。
2. 框架通过 props、插槽和回调交互，不访问后端内部、数据库、Pi 或本机文件系统。
3. 地址草稿、正文保持、状态布局与样例模拟均有职责注释。
4. 按用户确认的标签页独立能力和本轮两个框架需求实施。
5. 为标签组件追加可选 page 插槽；旧 toolbar/content 调用方式仍有实际示例使用。
6. 固定栏位仅使用中性单侧分隔线，控件没有完整边框与阴影叠加。
7. 通用框架位于 packages/ui；产品只组合框架。调试台使用明确标注的独立样例。
8. 工具栏与状态栏固定尺寸；刷新/停止按钮原位切换，重试不推动正文；页面和阅读状态切换验证通过。

未新增或修改公开业务接口，因此本轮无接口 catalog 变更。后续原生宿主和文件接入仍须同步契约、接口试验台与独立 API 测试。
