# 浏览器工作区技术验证结果

日期：2026-11-20。状态：**核心同会话链路验证通过；产品工作区尚未实施。**

## 结论

Electron WebContentsView + Playwright CDP + 现有 AgentService 可以满足当前需求中最关键的一环：用户在右侧浏览器登录后，Agent 操作同一页面，文件预览切换和用户接管不要求另开浏览器或复制登录凭据。

这证明该组合可以作为后续完整工作区的技术基础，不等于发现了一套即装即用的完整框架。暂不建议只为 Markdown/图片预览迁移整套 Theia；Theia 本轮没有运行验证。正式内容标签、文件打开、浏览器宿主服务和产品界面仍需后续建设。

## 实际执行

- 环境：Windows x64，Electron 45.4.1，Playwright Core 1.65.1；复用仓库 AgentService 和 Pi SDK 1.5.2。
- 最新完整运行：`npm.cmd run verify:real`，退出码0，**22项断言通过**。
- 真实模型：仓库配置的 `krill-ai-codex / gpt-5.6-sol`。自然语言要求根据“工作备注”“保存备注”等可见名称操作，不提供 CSS 定位器。
- 真实模型实际完成5次工具调用：observe、fill、click、scroll、screenshot；最终状态 completed。站点服务器记录与浏览器输入值共同验证写入成功。
- 确定性替身只决定工具调用，真实执行过程使用现有 AgentService；不存在替代 Agent 循环。
- 真人操作未参与。用户路径的登录与接管由自动化重放，使用合成账号，不接触真实用户账号。

## 发现与边界

1. Electron 分区与 Playwright 默认 context 的 Cookie/动态 target 管理存在差异，必须以真实页面身份核验；详见实验 README。未来多标签浏览器需补动态创建与关闭验证。
2. Windows 隐藏进程启动导致窗口捕获黑图；可见启动后原生窗口截图通过。PrintWindow 使用 DPI 感知，修正150%缩放的裁切。
3. 实验只读预览固定 Markdown 和合成图片，不是任意文件打开能力；图片测试素材为 SVG，不代表全部格式覆盖。
4. 验证只覆盖本地合成站点，不代表第三方登录/验证码、下载、弹出窗口、浏览器扩展和任意站点兼容。浏览器仍是技术原型。
5. 停止会阻止后续工具派发，但已提交网页动作不可撤销；正在执行的操作需收尾。本轮没有验证任意导航期间的即时中止。
6. 本轮没有修改生产业务接口，实验站点与父子进程命令不作为公开产品接口登记。正式接入时须按项目规则同步契约、catalog、试验台和独立 API 测试。

## 八条规则核对

- 范围限于批准的技术验证，没有扩展完整 IDE 或直接修改产品页面。
- Node Agent、Electron宿主、网页分别运行；渲染层不访问 Pi、文件系统或数据库。
- 关键工具、target 核验、切换、会话和截图代码有职责及原因注释。
- 采用用户确认的 Markdown/图片只读与 Agent 浏览器范围。
- 现有布局和接口保留，本轮不做旧版替换。
- 实验壳仅中性背景和单侧分隔；无嵌套完整边框或边框叠加阴影。
- 未新增产品通用组件；实验壳放 experiments，后续正式共用控件仍在 packages/ui。
- 导航/状态区固定占位；文件切换隐藏原生视图而不销毁浏览器，已验证状态保留。
