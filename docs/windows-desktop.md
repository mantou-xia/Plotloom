# Windows 桌面版

## 安装与首次启动

安装包面向 Windows x64，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\Plotloom`，并添加开始菜单入口。应用自带 Electron、Node 运行时和与 Playwright 匹配的 Chromium。首次使用聊天或 AI 写作时，在「设置 → 模型服务」填入自己的模型服务地址和 API Key，再选择默认模型。

应用数据默认放在 `%APPDATA%\Plotloom\data`。在「设置 → 存储」可查看当前目录。点击「更改位置」，选择一个存放目录并确认重启后，Plotloom 会在选定位置创建 `Plotloom-data`，复制现有数据，再切换到新目录。迁移失败时继续使用原目录。迁移成功后原目录保留为备份，确认新位置的数据完整后可自行处理旧副本。

同一 Windows 账号覆盖安装时，桌面版会继续使用原来的应用数据目录。如果旧数据在另一个位置，先关闭旧版，再在「设置 → 存储」点击「导入旧版数据」，选择含有 `sessions`、`agent` 等内容的实际数据目录。例如源码开发版默认使用仓库下的 `.plotloom-data`。确认后，Plotloom 会重启并打开旧数据的独立副本。旧目录和导入前的当前目录都保留，两份数据各自独立。导入失败时继续使用当前目录。

导入目录会保留模型供应商、已保存到应用中的 API Key、默认模型和思考档位，以及 Agent 人设和偏好。仅由源码版 `.env` 或环境变量提供的凭据需要在桌面版「模型服务」补填。同一桌面用户的界面偏好会随用户配置保留。从网页或另一台设备迁移时，在来源端「设置 → 存储」选择「导出偏好」，再在目标端选择「导入偏好」。偏好文件包含主题模式、主题色和书架排序。

小说正文保存在各小说选定的目录。Electron 的界面状态和浏览器缓存由 `%APPDATA%\Plotloom` 管理，源码开发版数据由 `.plotloom-data` 管理。关闭应用后再备份应用数据和小说目录。

选目录、Windows 正文写入及回收仍使用 Windows 自带组件。若企业策略禁用 Windows PowerShell，相关操作会失败。当前安装器尚未配置发布者签名。

## 构建

在 Windows x64 构建机准备 Node.js 24、项目锁定的 pnpm 和 Inno Setup 6。编译器不在默认位置时，用 `PLOTLOOM_ISCC` 指定 `ISCC.exe` 的绝对路径。

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd desktop:win
```

首次构建会准备锁定的 Electron 与 Playwright 浏览器文件。安装器写入 `output/desktop-installers`。应用使用 Electron 子进程启动已经编译的 Fastify 服务，桌面页面通过固定的 `plotloom://app/` 来源访问相对的 `/api/`。业务接口与 Web 版共用。

构建时只纳入生产后端、正式 Web 构建及运行所需资源。PowerShell、内置技能和浏览器都按实际文件路径分发。

Windows 安装器使用 Inno Setup 的 `lzma2/max` 实体压缩，缩小下载体积。安装后的运行时与浏览器文件均随包分发。

## Agent 使用记录

完成的回答下方可以点赞、点踩或填写反馈，评价按会话及轮次保存在本机。重复点击同一评分可撤回。设置中的「存储 → Agent 使用记录 → 导出压缩包」手动生成 `Plotloom-agent-usage.jsonl.gz`。解压后为 UTF-8 JSON Lines，首行 `manifest` 标明格式版本及时间，每条记录独立占一行。

- `session` 包含用户原话、回答、可见过程、模型、轮次状态与评价。通过消息和评价的 `turnId` 对应具体回答。
- `agent-write` 包含实际写入的相对路径及修改前后的文本，通过 `sessionId` 和 `turnId` 追溯。部分旧写入没有轮次标记。
- `workspace`、`document-revision`、`proposal` 包含小说工作区标识、文稿版本快照及候选采纳或拒绝状态，可用 `workspaceId`、路径和版本关联。

导出包含创作原文，交付前请由本机用户核对后自行提供。应用不会自动上传记录。导出依据本机当前保留的数据，已永久删除的聊天、附件二进制、本机凭据配置和浏览器数据目录不包含在包中。

验收覆盖接口参数错误、评价撤回和重启恢复、生成压缩包并解压核对原文与修改快照。Edge 在正式页面、接口试验台、组件调试台分别验证评价和导出，打包版 Electron 在隔离用户目录验证点踩、填写反馈、下载及解压。

## 0.1.0 验收

在本机 Windows 将安装包安装并复装到隔离目录，用仅保留系统路径的环境启动。通过真实窗口验证内置技能、剪贴板、模型协议替身驱动的 SSE 聊天、随包浏览器、项目文件读取、图片附件、中文路径正文保存、候选采纳、TXT 导出接口和重启持久化。独立回环请求因缺少桌面授权被拒绝。源码回归通过 122 项 API 测试和 53 项 UI、试验台测试。未在干净虚拟机或锁定 PowerShell 的企业环境验收。

存储设置在打包后的 Electron 窗口中使用隔离用户目录验证。模拟目录选择与确认，检查取消可返回设置、退出后重新启动会启用新目录、测试文件复制完整且原副本仍可读取。自动化测试验证目标文件夹被占用时继续使用原目录，组件调试台验证可搜索预览、提示出现时按钮位置不移动，以及浅色、深色和跟随系统实时切换。

模型能力随安装包分发，按已保存供应商中的模型 ID 和实际协议匹配。在隔离桌面用户目录预置旧版供应商记录后，验证 `/api/models` 返回已知推理模型的四档、未知模型仍只返回关闭，并通过 `/api/model-config` 保存超高档。用户的供应商记录无需重新保存。
