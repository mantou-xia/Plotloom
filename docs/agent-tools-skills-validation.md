## 八条规则核对
1. 只实现现有核心工具说明、技能开关/详情和轻量抓取；搜索服务未扩建。
2. 前端只消费公开 HTTP 契约，无 SDK/本机存储依赖。
3. 快照、持久化、工具目录、抓取与弹窗职责均有关键注释。
4. 全局开关与搜索范围已得到用户明确确认。
5. 保留有效的聊天/小说独立选择接口，没有删除旧入口。
6. 弹窗内部以背景和间距分层；条目按钮无边框，焦点采用阴影。
7. 复用并扩展 packages/ui 的 SkillItem，复用 Dialog/Switch；业务详情留在 apps/web。
8. 保存状态使用固定宽高区域，失败使用不占布局的提示；快速切换与失败几何已验证。
