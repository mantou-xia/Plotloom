## 关键决策与验收边界

1. 空会话仅有 SDK 元信息时不会自动落盘。适配层只初始化 SDK 自身格式的同一 JSONL，再重开交给 SDK，避免伪造用户消息或第二份会话索引。
2. accepted 等用户消息保存后才发送，使用真实条目 ID；最终事件等待 `prompt()` 完整结束并检查结果，不将 `agent_end` 误认成最终结束。
3. 请求开始/结束使用 SDK 自定义条目记录引用和 outcome。原因：服务强制退出可能发生在工具循环中间，仅看最后一条 assistant 消息无法确定整轮是否结束。标记不包含第二份消息正文，不支持自动续跑。
4. 查询返回公开内容块；推理内容、原始错误、供应商协议及私有路径不进入 HTTP。SDK 原始 JSONL 仍属于本机私有数据，可能保留供应商错误。
5. 默认选择保存独立的小型配置文件，消息仍只有 SDK JSONL 一份权威历史。没有数据库、消息队列或任务表。
6. 自动压缩及有限重试已由本机协议替身触发验证；真实模型只验收工具、流式、多轮、重启和停止，没有制造真实额度错误或超大上下文。创作质量、图像输入、长篇小说效果及百万上下文不在 P1 验收范围。
7. 固定数据目录仅支持一个服务进程，本地受控多次运行、备份与可靠性系统验收属于 P8。
