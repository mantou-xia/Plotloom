# 单栏 Agent 正式产品接入计划

2026-11-20。用户确认：直接替换旧简易聊天页，不保留旧入口；浏览器使用独立可见窗口；重新生成/重试保留历史，再执行最新一轮请求（会再次执行工具）。本版不接入分屏或浏览器工作区实验。

## 交付范围

1. 完善公开消息契约：轮次、可见过程、工具输入/结果、可判定的最终回答、停止/失败状态，以及最新一轮重试。注册试验台，维护独立接口及目录覆盖测试。
2. 后端按聊天隔离浏览器，使用 Playwright 控制独立可见窗口，支持导航、页面读取、点击、填写、按键、滚动与标签页。复用 Pi 执行循环，文件仍使用项目会话原生工具。普通聊天不扩大为本机文件工具。
3. 替换正式 ChatPage：组合 C01～C13 中现有可用能力，单栏消息与过程、附件预览、来源展示、复制、最新一轮重试、停止、模型/技能配置、页面加载失败恢复。完整 C09 图片组及分屏不扩展。
4. 消息列表在靠近底部时跟随，用户向上阅读时保持位置，并提供回到底部。切页与刷新通过公开快照恢复，不取消后端任务。
5. 真实产品浏览器验证：简单对话、项目写文件、浏览器导航/填写/点击，以及停止、失败、重试、刷新、滚动。模型协议替身用于确定性回归，另用已配置真实模型做隔离目录验收，明确区分结果。

## 实施决策

- 业务组合放 `apps/web`，复用 `packages/ui`，不复制通用组件。
- SDK 未在正文开始前承诺最终回答时，先显示为可见过程；只有模型消息结束、确认非工具调用后才归为最终回答，不能用首个文本增量猜测阶段。
- 页面以公开会话快照为权威，生成中轮询并在 SSE 事件后刷新，避免各类增量拼接丢失顺序以及刷新后展示不同。
- 最新请求在后端保存，重试入口校验目标消息与当前最新请求一致；附件/引用/显式技能随原请求重放，不由前端拼造文本。
- 浏览器工具只在使用时启动；数据与会话生命周期归后端。网页和文件内容均作为资料，不作为应用控制指令。现有 Electron 实验保持独立。
- 状态反馈使用既有固定占位或浮层；不以新提示条挤动输入框或消息。
