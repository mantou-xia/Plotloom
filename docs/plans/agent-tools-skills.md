# Agent 工具与技能详情

## 已确认范围
- 统一核心工具用途、参数与聊天启用条件，技能页点击条目查看详情。
- 全局开关作为所有聊天的技能准入条件；关闭从下一轮生效，进行中保留固定快照。
- 未显式覆盖的聊天自动发现全局启用的技能；已有聊天/小说选择仍用于缩小范围。
- 搜索沿用 browser，独立搜索服务后续讨论；新增 web_fetch 读取静态网页正文。

## 实施顺序与原因
1. 后端集中提供工具目录和各聊天工具集合，避免前端猜测权限。
2. 技能持久化 enabled 并在每轮快照过滤；保留现有覆盖接口，因为其用于聊天独立选择。
3. web_fetch 限制协议、时长和正文大小，支持取消；动态或登录页面交给已有 browser。
4. 复用 SkillItem、Dialog、Switch；详情业务组合位于 apps/web，状态反馈保持位置稳定。
5. 更新公开目录、独立接口测试、试验台验证及浏览器交互验收，逐条核对八条规则。
