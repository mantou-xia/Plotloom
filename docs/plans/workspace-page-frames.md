# Markdown 阅读器与浏览器页面框架

2026-11-20。用户要求标签页能自定义框架，先交付 Markdown 文本阅读器和浏览器框架。

1. 为 WorkspaceTabs 追加完整 `page` 插槽；原 toolbar/content 用法保留。完整页面自己管理工具栏、滚动与内容高度，避免嵌套两层滚动容器。
2. packages/ui 提供 MarkdownReaderFrame：文件信息、打开操作回调、只读阅读区、加载/空文件/失败状态；复用 MarkdownRenderer、Button、ScrollBox。
3. packages/ui 提供 BrowserFrame：导航回调、受控网址与独立地址草稿、刷新/停止、网页内容插槽、状态栏。无网络、CDP、文件或 Pi 调用，不自动创建 iframe。
4. apps/web 的两个标签页组合相应框架，真实宿主和文件服务仍保持未连接状态。独立调试台用明确标注的本地样例验证状态与回调。
5. 同步组件导出、目录、公开参数说明；验收独立展示、完整页面嵌入、滚动保留、导航与停止、快速状态变化、窄屏和自定义工具栏。

采用可选参数扩展现有标签框架，不删除旧入口。只建设当前两个明确类型，不引入插件注册系统；共同样式和状态布局只在已有两处复用范围提取。

状态：两类框架、完整页面插槽与工作区接入已完成；验收见 `docs/workspace-page-frames-validation.md`。实际文件服务与浏览器宿主仍待后续接口接入。
