## 3. 两项决策（2026-11-18 已确认）

推荐首版路径：

**P2 工作区、版本、逐处采纳和技能管理基础 → P3 内置写作接入及首版后端整体验收 → P7 产品工作台 → P8 本地试用。**

原 P4/P5 的自动事实提取、人物知情重建、向量检索，以及 P6 的高级偏好学习和自动规划等扩展保留为后续规划，不阻塞首版界面。P6 中必要的创作质量评测、全链路接口验收和前端接入资料合并到首版 P3 退出条件，不能以范围收窄为由省略验证。

保留原阶段编号，避免已有验收文档和聊天引用失效；只有依赖关系与交付范围调整。用户确认前不直接删除 P4/P5/P6 的原有交付承诺。

1. 同步修订 architecture、roadmap、project-structure、README 和两份方案文档，明确首版阶段依赖及历史图的适用范围。

4. 先落工作区和文件版本能力，再做逐处候选及冲突检查，随后完成技能管理与来源范围。后端工具与 HTTP 共用业务用例。
