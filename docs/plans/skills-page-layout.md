2026-11-19。用户确认使用分段标签、原生文件夹选择器，并授权删除输入路径的旧接口。

## 能力盘点

- 页面已有清单、刷新、不可用提示；搜索、分类、导入尚未接入。
- 后端已有创建、复制、读取和编辑资源、版本冲突保护、删除、依赖诊断、工作区默认技能、聊天覆盖/继承、按需及显式加载。
- 仓库内置 novel-writing；个人分类包括 custom 与 imported，数量来自真实列表。

## 实施顺序

1. 先在 packages/ui 开发 SegmentedControl 及独立调试台示例；复用 Input、Button、PageLayout。
2. 在技能 feature 开发 SkillItem；一次性业务展示不放入通用组件库。
3. 用 POST /api/skills/import-folder（空对象）替换 POST /api/skills/import（root）。复用原生选择器，与项目共用一个实例；取消返回 skill:null，成功返回 skill。
4. 最后拼装页面：搜索名称和描述、系统/个人分类及数量、双列列表和加载/空/错误状态。导入成功转到个人分类并清空搜索。
5. 同步迁移试验台、接口测试与文档，执行类型、UI、HTTP、试验台和浏览器验证。

## 范围

不增加编辑、删除等页面入口。不保留旧路径输入兼容协议。前端只访问公开接口，不访问本机文件或后端内部实现。
