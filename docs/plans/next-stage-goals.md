| --- | --- | --- |
| 项目 Agent 可控执行 | 默认使用受项目范围约束的只读工具；有副作用的项目文件操作逐次审批；终端和有副作用的浏览器操作按隔离验证结果开放。公开接口提供待审批快照、决定和结果，过程区显示实际状态。 | 用户能理解并决定当前操作。拒绝、停止、过期、重复决定与中断都可验证。对隔离尚未验收的工具，受控试用配置中保持禁用。详见 [Pi 调研](pi-tool-permissions-and-isolation.md)。 |
| 作者可操作的最小创作闭环 | 产品 Web 接入现有小说登记、章节编辑、选区和参考资料、P3 候选、P2 差异和历史接口。 | 作者能从正式入口独立完成打开书籍、编辑章节、对选区发起改写、预览差异、逐处采纳或拒绝、恢复版本、导出。覆盖外部改稿、旧版本冲突、停止及刷新后找回草稿或候选。 |

## 后续增强

小说产品的下一阶段需求与待讨论决定持续记录在[小说创作产品打磨清单](novel-authoring-product.md)，从建书、旧稿导入和本书聊天展开到角色阶段、分角色对白、文风审阅与纯文本导出。

| 能力 | 起步范围与进入条件 |
| --- | --- |
| 长篇事实与上下文检索（P4—P5） | 用带章节时点、出处和版本的事实及人物知情记录，先评测跨章召回、别名、视角泄漏、资料更新失效；根据样本表现再选索引。 |
| 质量评测与诊断（P6/P8） | 扩展固定样本，比较模型、提示版本和候选质量。优先关联请求、工具、耗时、用量和失败原因，保留本地脱敏结果。 |
| 右侧资料工作区 | 先服务写作闭环所需的正文、来源定位和版本预览。独立浏览器接入右侧面板、图片浏览、Electron 打包单独排期。 |
| 更深的任务恢复 | 根据试用中断频率，评估步骤级恢复。先处理副作用的结果核对，自动续跑和任务队列单独立项。 |
| MCP、子 Agent 与扩展工具 | 待权限、凭据、审批和执行隔离成熟，有明确资料源或可评测的独立审校任务时再接入。Pi CLI 与 SDK 的 MCP 接入方式不同，按后续锁定版本复核。 |

## 验收与范围

- P7 创作闭环与 P8 工具执行改造可并行，以独立 HTTP/SSE 契约衔接。
- 新增或修改业务接口时，同步更新 `packages/contracts/src/catalog.ts`、`apps/api-demo`、`tests/api`、`tests/demo` 及阶段验收记录。试验台实际验证正常、拒绝、停止和适用的异常路径。
- 已确认新旧项目会话统一使用受控工具，历史保留。文件审批的实现和试用边界见 [项目工具审批验收](../project-tool-approval-validation.md)。终端与网络工具的隔离仍需单独验收。
