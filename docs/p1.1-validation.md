## 交付范围

- 模型能力：支持档位、上下文窗口、最大输出、输入类型。
- 默认与会话配置：模型和思考档位保存/恢复，既有会话可单独切换模型。
- 会话名称：创建时命名及之后修改，列表、详情展示。
- 上下文：占用估算、手动压缩、取消压缩；原始历史保留。
- 累计用量和工具：消息/工具计数、已保存 token 合计、工具描述/参数/启用状态。
- 思考文本：SSE `thinking_delta`、历史 `thinking` 块、页面独立显示；过滤签名、加密数据和已隐去内容。
- 原 8 个操作保留，新增 8 个；试验台共 16 个接口、4 个模块、10 类 SSE 事件。

## 决策与规则核对

| 规则 | 核对 |
| --- | --- |
| 不过度设计 | 只实现已确认的七类能力与思考内容，无分支、指令队列、动态工具管理或凭据页面 |
| 前后端完全解耦 | 页面只依赖公开契约及 HTTP/SSE；SDK、目录及保存均由后端独立处理 |
| 关键函数有注释 | 能力校验、会话互斥、配置保存、压缩取消时序、思考映射、页面选择器和测试均解释职责/原因 |
| 模糊需求先澄清 | 在实施前确认七项范围，用户追加思考内容后纳入计划 |
| 替换旧接口先确认 | 本次增加字段和入口，原操作继续存在；未删除 P0/P1 接口，无额外兼容层 |
| 前端边框与层级 | 复用既有背景和间距，无新增完整边框嵌套、彩色边框或 border/shadow 叠加 |

手动压缩直接复用 SDK；开始前占用会话，取消等待完整收尾，避免与生成/改配置互相覆盖。SDK 可能分别摘要历史和截断轮次，因此压缩用量按实际多次请求累加。查询类操作不发起模型请求，不因缺少凭据阻断已有数据读取。

P2、P7 产品前端及 Electron 不在本轮范围。
