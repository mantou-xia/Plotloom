# P2.1 技能与小说聊天验收

日期：2026-11-18。结论：P2.1 管理、加载接入和聊天关联已完成。P3 小说工具与真实创作效果尚未验证，不将本阶段视为章节生成闭环。

依据：[实施计划](plans/p2.1-implementation.md)、[接口说明](api/p2.1-skills.md)、[路线图](roadmap.md)。本轮无 `.cursor/rules/*.mdc` 或 space 约定上下文，按根 AGENTS.md 和用户确认范围执行。

## 交付范围

- 应用级内置、自定义与完整目录导入技能；列表、详情、文本资源编辑、复制、删除，保留二进制附件且不执行脚本。
- 工作区默认、聊天完整覆盖及恢复跟随；空列表关闭；修改从下一条消息生效。
- 请求级技能快照、摘要发现、read_skill 受限读取、消息 skillIds 显式加载；缺少声明工具明确诊断，不伪装可用。
- 小说聊天固定归属、按小说列表和全部最近列表；消息与关联均由 SDK JSONL 保存，不复制聊天历史。
- 新增 15 个公开接口并扩展消息参数，试验台现有 48 接口、10 模块。

## 试验台实际操作

Playwright 操作独立临时数据目录的真实页面与后端，最终记录 24 项检查，覆盖全部 15 个新增接口及工作区创建、消息发送、停止共 18 个接口。停止场景另发起一条等待消息，因此实际业务请求为 25 次。成功 JSON 响应均显示“检查通过”，技能引用内容在 SSE 正文和工具时间线出现，停止显示“已停止”。

| 主动错误场景 | 实测 |
| --- | --- |
| 旧版本编辑 | 409 SKILL_VERSION_CONFLICT |
| `../secret` 资源路径 | 400 INVALID_REQUEST |
| 删除内置技能 | 409 SKILL_READ_ONLY |

最终页面无 JavaScript 运行异常，控制台仅以上 3 次预期错误。截图已检查，技能参数、继承结果和流式工具结果可见；本机证据为 `output/playwright/p21-browser-run.js`、`p21-skill-run.png`、`p21-settings.png`，不作为运行依赖提交。

初次页面导入发现 Windows 新目录 rename 偶发 EPERM，独立连续安装探针复现。修复为仅创建版本文件、校验完整内容后原子发布清单；同版本文件按内容核对后重用，不覆盖已发布内容。修复后连续安装、全部接口回归及完整浏览器流程通过；没有用重试掩盖该问题。

## 限制与后续

- 当前本机模型配置报告 configured:false；本轮未调用真实供应商。协议替身验证接入、权限和工具循环，不能证明模型选技准确率或小说质量。
- 内置 novel-writing 的 SKILL.md、人物参考及模板已交付；P3 的 list_documents/read_document/search_documents/propose_change 尚不存在，当前明确显示不可运行。P3 接入这些工具后再验证真实大纲创作、冲突讨论、选区候选与采纳闭环。
- runnable 仅检查工具声明；自然语言环境依赖由用户核对。无脚本执行、插件代码加载、在线市场、依赖安装或聊天迁移。
- 已停用指令可能留在历史中，权限以本轮资源集合为准；不承诺模型遗忘历史。工具查询在下一次消息装配后刷新，技能设置查询直接展示下一轮配置。
- 单服务使用同一数据目录；未承诺断电事务，完整应用备份在 P8 验证，P2 资产备份不含技能及聊天。
- Fastify 既有弃用提示仍存在，不影响本轮结果。

## 六条铁律及接口交付核对

| 要求 | 结果 |
| --- | --- |
| 不过度设计 | 仅文件技能、启用和关联；不建设插件运行时、工作流或额外数据库 |
| 前后端完全解耦 | 前端只使用 contracts 与 HTTP；application 不依赖 Pi，agent-pi 只接收通用资源快照；独立接口可运行 |
| 关键函数清晰注释 | 发布清单、请求快照、资源隔离、版本刷新、元数据保存均说明职责及原因 |
| 冲突先澄清 | 工作区与聊天优先级先获用户明确“可以”后实施 |
| 替换前确认 | 保留原通用会话接口；新增技能接口，无删除现用旧入口或无用兼容分支 |
| 边框与层级 | 复用试验台背景/间距及单侧中性分隔，没有新增嵌套完整边框或阴影描边 |
| 接口登记与实际操作 | 15 个新增接口及消息新增字段已登记；48 路由全目录覆盖，浏览器实测通过 |
| 独立测试与结果记录 | 48 项回归及阶段实际操作通过；真实创作效果明确留待 P3 |
