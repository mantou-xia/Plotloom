## 从样文得到的调整依据

人写样本直接进家门，用照片、衣物和拖鞋承接思母，随后转到打扫和电话。悲伤中有回来的庆幸，没有把整段不断推向更强烈的悲痛。叙述贴近人物，允许不耐烦、判断和吐槽；必要的解释交代铃声为何陌生、为什么不能浪费泡面。直接心理、常见措辞和重复都实际存在，不能用它们是否出现判断文笔。

因此，入口与三个写作参考由 5532 字符精简到 3505，约减少 37%（含 Markdown 标记，不是 token 数）。保留两份上游方法的任务分流、按需审读、对白和保真思想及许可，撤去每段信息增量、每次成稿多遍删改的统一要求。起草先学习样文的叙述距离、详略、转场和情绪分寸；审读按需局部处理，改稿同时保护事实与感情。普通现场细节允许创作，已有剧情关系和知情范围继续约束连续性。

附件明确作为资料处理，其中的文字不自动成为用户指令。作者样本未写进通用 Skill，也未把该书人物或特定口吻设成所有小说的标准。交付仍使用既有审校、确认和候选入口。

## 测试条件与完整结果

使用 `gpt-5.6-sol`，思考关闭。每次新建隔离小说及聊天；整章使用相同前三章、六点大纲及作者样文，通过公开消息接口引用样文。思母和短段改稿不附样文，使用同一原稿和润色指令。所有模型输出原样保存，没有人工修补后再当作模型成绩。

整章样文就是同一故事的第四章，本次属于参照表达的实验，不能证明对新故事的泛化效果。模型采样存在波动，各轮仅一份整章，不能把差异全部归因于 Skill。

- 短段：调整前删除“弟弟不识字”；精简版保住不识字，却把“等她下班回去念”改成“晚上还等着她念”，丢失工作结束这一条件并增加等待状态，语义保真未通过。
