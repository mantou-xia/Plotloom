# C04～C06 Agent 执行过程实施计划

日期：2026-11-20。状态：组件、调试台和 C03 组合已完成验收，见 [验收记录](agent-process-validation.md)。真实接口与聊天页面接入待后续阶段。

## 已确认目标

C03 的内容插槽承载整个 Agent 执行过程：公开思考、过程说明、工具调用、步骤、重试、上下文整理、失败与停止等信息按发生顺序穿插展示。最终回答由调用方展示在过程区外。

- C04 改为 `ThinkingContent`：只渲染一段公开思考文本或摘要与流式更新，不管理整体阶段、滚动、折叠，不补造模型内部思考。
- C05 `ExecutionTimeline`：按调用方数组顺序展示全部过程节点；统一管理默认定高、内部滚动、展开全部、回到最新与首次最终回答时折叠。
- C06 `ToolCallItem`：工具名称、操作摘要、执行状态，以及展开查看实际输入和输出。状态在原位置更新，不移到列表末尾。
- 用户已确认旧 ThinkingPanel 无需保留；清理其入口、实现和无效调试引用，不建设兼容层。保留旧验收文档作为历史记录并标明已被本方案取代。
- 本轮仅组件库、调试台和 C03 组合，真实聊天与业务接口接入留待后续阶段。

## 参考与设计决策

参考用户指定的 Ant Design X ThoughtChain 页面：纵向连接线、节点标题和描述、运行/完成/失败/停止状态、可展开详情。

参考地址：`https://ant-design-x.antgroup.com/components/thought-chain-cn`。

通过实际浏览器查看页面及可折叠样例，结合官方文档核对行为。本轮独立实现，复用项目 Button、ScrollBox、MarkdownRenderer 与 lucide-react，不引入 Ant Design X 依赖。

- 连接线采用中性灰实线，详情用浅灰背景与间距；不嵌套完整边框，不叠加阴影。
- 思考和过程说明默认可读，工具输入/结果默认收起；节点可独立展开回顾，但不产生第二个纵向滚动容器。
- 工具状态与折叠图标固定占位；完成/失败不自动展开详情。用户查看历史节点时暂停跟随，避免展开后被拉到底部。
- 不按类型聚合或时间重新排序，稳定 id 保持原节点及其展开选择；相邻增量由调用方更新对应 id 的内容。
- 通用展示数据包含 thinking、message、tool、event 四类；event 接收实际标题、说明与状态，承载步骤/重试/上下文整理/结束信息，不预造业务事件。
- 首次明确进入最终回答自动折叠一次；后续完成、失败、停止和增量不覆盖用户选择。新任务用 key 重建。

## 实施顺序

1. 建立轻量思考内容块、共用的节点布局和工具项，注释公开输入与状态职责。
2. 将现有整体阅读控制迁到 ExecutionTimeline，组合四类节点；清理 ThinkingPanel。
3. 为三个公开组件注册独立调试样例与参数；C03 使用真实过程列表样例，演示按序追加与原位状态更新。
4. 同步组件文档与主计划；说明实时接口当前缺少最终回答阶段和完整工具详情等契约，不能宣称已接入。
5. 类型检查、UI 导出目录覆盖与构建；浏览器验证顺序、原位更新、流式、详情、跟随/上翻、整体展开/折叠、键盘、停止/失败、空数据、窄屏、减少动态效果与 C03 回归。

## 规则与范围

- 按根 AGENTS.md 八条规则验收；本轮无 `.cursor/rules`、无可用 `.mdc`，约定的 space 上下文不存在。
- 状态反馈不挤动已有内容；允许用户主动展开/收起以及已确认的最终回答自动折叠改变高度。
- 无公开业务接口新增或修改，本轮不触发接口试验台交付；页面接入时须另行满足其全部要求。
