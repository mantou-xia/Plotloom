# 设置二级页面验收

日期：2026-11-20

## 范围与方案

- 设置与主页面共用同一 GlobalLayout，进入时切换左侧导航和右侧正文，左上角返回。
- 设置分类包括模型服务、默认模型、技能和外观。返回与分类共用 SidebarNavItem 的悬停和焦点反馈。
- 设置沿用默认外壳的侧栏底色、可调宽度、栏间距和正文圆角。
- 进入设置时保留主页面挂载和测量尺寸，并隐藏、禁用交互；返回恢复原页面与入口焦点，避免丢失草稿或重算侧栏宽度。

## 验证结果

- 供应商详情支持原位编辑。隔离浏览器验证了密钥掩码、剪贴板内容、原位保存、连接成功 Notice、模型抽屉向右收回和左侧删除确认。试验台使用测试凭据调用复制接口返回 200。
- 独立接口测试确认供应商列表不含密钥，复制响应携带 `Cache-Control: no-store`，无 JSON 请求返回 400，异站请求返回 403，未知供应商返回 404。接口目录覆盖 72 个业务路由。

- 单 Key 供应商验证使用独立数据目录与本机模型目录服务。分别核对两种协议的鉴权头、停用拒绝新会话、目录错误 502、空模型列表、删除后重启。旧单端点配置的生成和恢复测试通过。
- 浏览器在试验台触发六个供应商接口，覆盖成功响应和不存在的供应商。新增供应商缺少 API Key 返回 422。产品设置页使用测试上游验证保存后自动展示目录、搜索、逐行添加与移除、返回后回显，以及更多设置键盘切换。目录测试覆盖 69 个公开路由。

- 供应商配置使用隔离数据目录验收。独立接口测试覆盖并发创建冲突、编辑不存在的标识、无效地址或模型、变更服务源需重新填写密钥、响应隐藏密钥、保留旧模型能力，以及重启恢复默认模型。测试模型服务实际接收生成请求，同一聊天更新地址后下一轮访问新服务。
- 通过接口试验台页面向隔离后端执行 GET、POST、PUT，正常请求均返回 200，重复新增返回 409，无效模型列表返回 400。目录覆盖测试核对全部 66 个路由。
- 产品浏览器验证覆盖新增供应商、编辑时密钥留空、模型列表更新、默认模型保存、全局技能切换及返回。页面和试验台均通过公开 HTTP 调用，未使用真实商业供应商凭据。

- web、ui、ui-demo 类型检查通过；web 生产构建通过（构建提示大体积 chunk）。
- 浏览器 22 项断言通过：导航替换、返回来源页面、首次及重复进入后的侧栏宽度、草稿保留、主题保存和刷新恢复、自定义颜色弹窗。
- 桌面 1440px、平板 768px、手机 390px 已截图核查；正文无横向溢出，返回入口可见。
- 连续切换五种主题色，保存提示出现、更新及消失时，设置区域的位置与尺寸保持一致。
- 浏览器验收脚本与截图保存在忽略目录 `output/playwright/settings-*`。

## 设置结构组件提取

- `SettingsSection` 统一分组标题、可选说明、Card 背景与相邻行分隔；`SettingsRow` 统一名称、说明和控件插槽。两者在 `packages/ui` 维护，主题色页面已接入。
- 页面导航、主题数据、保存反馈仍由应用管理。未增加任何业务设置或接口；无旧业务协议替换。
- 组件调试台分别登记两个组件及标题、说明、尺寸参数，提供多行组合、选色、无说明和窄容器样例。
- web / ui / ui-demo 类型检查通过，公开组件目录覆盖测试通过。
- 组件浏览器 8 项检查通过：三个行组合、开关快速切换稳定、下拉选择稳定、单侧分隔、参数更新、280px 不溢出、无说明和选色交互。
- 提取后原页面 22 项浏览器回归全部通过；桌面及窄屏截图重新核查。
- Vite 在运行期间缓存了旧 package exports，重新加载开发配置后识别新入口，回归通过；无需修改接口导入方式。
- 八条规则复核：仅提取本次明确要求的设置结构；前后端解耦；职责注释齐备；需求无冲突；无旧协议替换；中性单侧分隔且不叠加阴影；通用组件及样式在库内并登记调试台；交互和保存反馈无位移。

## 八条规则核对

Select 宽度修复补验：浮层从固定按钮宽度改为内容宽度，按钮宽度作为下限，可用空间作为上限。10 项浏览器检查通过，覆盖短中文单行、长文案上限与换行、触发器位置尺寸稳定、搜索、禁用及多选。修复位于组件库共享 CSS，仅调整现有样式并说明原因，无业务接口或状态逻辑变更，不增加边框、抽象或页面特例。截图：`output/playwright/select-content-width.png`。

1. 只重组已有设置和导航，不增加虚构设置、接口或兼容机制。
2. 无后端或公开业务接口变更，原主题偏好仍由前端本地存储负责。
3. 二级导航、焦点恢复、主页面保留及平铺布局均有职责注释。
4. 按用户指定的二级页面、返回和设置侧栏实现。
5. 本次为明确要求的布局重构，不替换旧业务接口；已有主题色能力继续复用。
6. 侧栏只用中性单侧分隔线；设置分组以背景区分，不叠加边框和阴影。
7. 通用布局能力留在 packages/ui，具体设置内容由 apps/web 组合；调试台登记平铺参数样例。
8. 保存反馈复用浮层提示，连续切换及反馈消失均已验证无布局位移。
