# Card 材质验收

日期：2026-11-19。

## 交付行为

- `Card.material` 支持 `normal`（默认）和 `liquid-glass`，原有普通卡片默认外观保留。
- 液态玻璃通过 SVG 背景滤镜折射背后的真实页面内容；不复制页面 DOM、不截图、不要求传背景图片。前景 children 不参与滤镜处理。
- 位移图沿用用户 `liquid-glass.html` 的凸面光学模型，按卡片尺寸与圆角生成，MIT 许可随源码保留。
- `backgroundColor` 在玻璃材质中作为 10% 染色；`bordered` 开启时关闭材质阴影。
- 调试台「基础组件 → Card」可切换材质，液态玻璃样例使用真实文字和色块作为背景，按钮可以移动背景。

## 使用边界

- 真正的 SVG 背景折射仅对 Chromium 启用；其他引擎保留透明模糊玻璃。未声称跨引擎具有相同折射效果。
- 卡片后面需要有可见内容。纯色背景无法显现位移；祖先的透明度、滤镜和遮罩可能限制背景采样范围。
- 折射模型使用统一圆形圆角；复杂的不同角/椭圆 CSS 简写按左上角近似。普通材质仍保留原生 CSS 圆角行为。
- 减少透明度和强制颜色媒体查询会关闭滤镜，使用实色背景；本次实际浏览器验证了强制颜色分支。

## 七条规则核对

1. 仅新增当前需要的两种材质、调试参数及相关验证，无外部运行时依赖。
2. 全部位于前端组件与调试台，不涉及后端或业务接口。
3. 材质职责、折射计算、观察器清理及浏览器降级原因有注释。
4. 已经用户明确：作用于背后的任意页面内容。
5. 本次为现有 Card 新增属性，未替换旧接口或删除旧能力。
6. 边框为中性灰实线，带边框时无材质阴影；示例不嵌套完整边框。
7. 通用材质与样式维护在 `packages/ui/src/card`，调试台通过公开 props 组合。

本次无公开业务接口变更，接口试验台登记与后端接口测试不适用。
