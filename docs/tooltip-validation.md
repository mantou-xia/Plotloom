# Tooltip 验证记录

日期：2026-11-19。

范围：仅实现参考中的提示气泡，不实现触发按钮的文字切换动画。组件通过 `@plotloom/ui/tooltip` 导出，在调试台反馈组件分组展示。

## 验证结果

- `pnpm ui:build` 通过，包含调试台类型检查及生产构建。
- 浏览器通过：悬停显示、移入气泡保持、移出关闭、Tab 聚焦显示、Esc 关闭、ARIA 说明关联、禁用不显示。
- 长文字换行验证：气泡宽 280px、高约 82px，截图检查无截断；默认上方显示，在靠近画布顶部时自动翻转到下方。
- `pnpm test:ui` 首轮 20/20 通过；最终复查 19/20，目录覆盖检查因工作区同期新增的表单组件导出尚未登记而失败，Tooltip 导出已正确登记。
- `pnpm --filter @plotloom/ui typecheck` 被 `src/form/input.tsx`、`checkbox.tsx`、`switch.tsx` 的 style 类型错误阻塞；未修改这些任务外文件。
- `git diff --check` 通过。

## 七条规则核对

1. 只增加气泡及必要的调试台参数，复用已有浮层依赖。
2. 纯前端组件，无后端依赖或业务接口改动。
3. 职责、触发器契约、ARIA 关联和箭头实现有注释。
4. 用户已明确仅实现气泡。
5. 新增组件，未替换旧接口或旧实现。
6. 气泡无边框，以背景和阴影区分层级；未改变触发按钮样式。
7. 组件及样式位于 packages/ui，调试台通过公开 props 组合。

全仓检查仍有上述任务外阻塞，不标记全仓可合并。
