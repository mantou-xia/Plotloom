## 交付范围

- 新增独立 `@plotloom/ui/thinking-panel` 导出，复用 MarkdownRenderer、ScrollBox、Button 与项目图标库。
- 默认整体 312px（含 36px 工具栏），超出内部滚动；「展开全部」取消限制，恢复定高保留阅读位置。
- 流式底部跟随，上翻暂停跟随；回到最新入口固定占位，隐藏时焦点交回阅读区。
- 首次进入明确最终回答阶段自动折叠一次；后续手动展开、停止、失败、完成与增量均不重复自动折叠。空白内容不制造面板。
- C03 调试台直接替换已获准清理的临时 `ExampleThoughtContent`，无兼容分支；完整展开可撑高右侧，粒子保持原尺寸。
- 组件目录包含八个独立状态：短文本、长文本、流式、最终回答、完成、停止、失败、空文本；公开文本、阶段、流式与高度可调。

## 验证中修正

- 状态复核发现「最终回答 → 失败/停止」不应按离开完成态重置展开选择。改为每个组件实例记录是否已进入最终回答，只自动折叠一次；新增三项断言验证失败、停止及恢复完成后的选择保留。
- 初次脚本用 `getByLabel` 精确查询原生 select 未匹配，改用实际可访问角色与名称 `combobox` 定位；修正后完整运行通过，没有削弱行为断言。

## 八条规则核对

1. 只实现 C04 及必要的 C03 示例组合，未提前实现后续组件。
2. 纯展示 props，不请求后端、不依赖应用内部状态或 SDK。
3. 阶段折叠、滚动跟随、尺寸释放与示例模拟输入均有职责和原因注释。
4. 开工前已讨论并确认固定阅读高度与完整展开行为。
5. 用户明确允许替换临时组件；临时代码已清理，旧聊天页面尚未替换。
6. 新增样式无完整边框及层级阴影，复用无边框按钮与滚动容器；焦点沿用组件库样式。
7. 通用能力与样式在 `packages/ui`，独立登记与公开参数示例齐全。
8. 固定尺寸工具栏、固定占位入口，已覆盖反馈出现/消失及快速切换；未用动画掩盖位移。

本轮未新增或修改公开业务接口，接口试验台要求不适用。真实聊天接入、任务 key 绑定与后端最终回答阶段识别留待页面组合阶段。
