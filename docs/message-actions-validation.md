# C12 MessageActions 验收

日期：2026-11-20。

## 实现范围与原因

- 在 `packages/ui` 提供 `@plotloom/ui/message-actions`，只实现首批复制、重新生成两个操作，复用 Button、Tooltip 和 Lucide 图标。
- 复制直接写入原文，避免 Markdown 解析造成内容变化；空白内容禁用复制。成功与失败在原按钮内反馈，2.2 秒后恢复。
- 重新生成交给可选回调：没有回调则不显示入口；回调 Promise 与宿主 `regenerating` 均可控制忙碌，内部同步锁避免连续点击重复请求。失败保留重试入口。
- 32px 按钮固定占位，读屏反馈脱离文档流，状态变化不挤动邻近操作。没有后端、应用 feature 或消息替换逻辑依赖。
- 调试台在「AI 对话组件」注册七个样例，可调整原文、回调可用性、生成中、单独禁用和全部禁用。

## 八条规则核对

1. 不过度设计：只实现复制、重新生成，不增加反馈评价、分享或扩展框架。
2. 前后端解耦：只使用 props、浏览器剪贴板和回调，没有业务接口变更。
3. 关键注释：复制原文、过期反馈、异步锁、布局稳定均有职责说明。
4. 需求明确：按 C12 已确定范围实施。
5. 旧实现：新增独立组件，不替换旧接口或旧组件。
6. 边框规则：操作栏无边框；复用无边框 ghost 按钮和既有聚焦态。
7. 组件归属：通用组件与样式位于 `packages/ui`，调试台仅提供组件样例。
8. 状态稳定：固定按钮尺寸和脱离文档流的反馈，覆盖出现、消失和快速切换。

本轮没有新增或修改公开业务接口，不涉及接口目录和接口试验台变更。真实聊天页面组合与重新生成业务协议尚未接入，不计入本次完成范围。
