# 会话条目叠放交互验收（2026-11-18）

## 范围

用户确认先完成组件样式，不实现后端业务。SidebarSessionItem 移除左侧图标与省略号操作区，右侧改为相对时间、任务状态、置顶和归档的叠放区域。沿用现有行高、主题、选中效果与 Button，不改变功能导航和设置条目。

- 时间由 `timeLabel` 提供；状态由 `status` 提供，支持正在进行、已完成未查看、失败。
- `pinned/onPinnedChange` 为受控置顶；`onArchive` 只通知调用方。调试台只更新示例置顶状态和记录回调，不排序、不删除会话，不持久化。
- 悬停或焦点进入向左展开，离开后收起。触屏常展开，减少动态效果时停止过渡和旋转。
- 窄行宽时只读的时间和状态收起为图标，操作按钮始终保留完整点击区域；完整信息仍通过 title 和可访问说明提供。
- 调试台增加状态与时间参数、已置顶参数和三种新样例；组合侧栏同步展示这套交互。
- 交互参考 LeiBox Stacked Metadata，设计参考 Gabriel。源包已检查并保留在本地 `output/stacked-metadata-reference`；组件基于项目现有控件重写，没有引入参考演示场景、字体或新依赖。

## 七条规则核对

1. 只实现已确认的组件展示及交互，不扩展后端、持久化或产品业务。
2. 数据通过 props，操作通过回调；无应用内部或后端依赖。
3. 受控操作隔离、整行宽度测量与观察器清理、操作区固定和窄宽度压缩均有注释。
4. 已先澄清交付范围，再按用户“只完成组件样式”的回复实施。
5. 按用户明确要求移除会话左侧图标和省略号入口，更新全部现有示例调用；不保留废弃入口，不修改业务接口。
6. 标签与按钮无边框；层级使用背景、间距与叠放，焦点使用内侧阴影。
7. 实现和样式统一在 packages/ui，调试台只展示组件与公开参数。

没有公开业务接口变更，无需修改接口目录或后端测试。
