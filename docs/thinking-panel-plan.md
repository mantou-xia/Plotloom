# C04 ThinkingPanel 实施计划

> 历史记录：2026-11-20 用户确认旧形态无需保留，已由 [C04～C06 统一过程方案](agent-process-plan.md) 取代；此文档不再作为当前实现说明。

日期：2026-11-20。状态：组件、独立调试台与 C03 组合已实现并完成验收，见 [验收记录](thinking-panel-validation.md)；真实聊天接入待后续实施。

## 已确认范围

- 交付 `packages/ui` 组件、独立调试台与 C03 组合示例；本轮不接入聊天页面、后端或公开业务接口。
- 默认固定高度、内部滚动；用户可点击「展开全部」取消高度限制、撑开整体，再恢复固定高度。C03 左侧粒子保持原尺寸。
- 用户已明确允许用 C04 替换临时 `ExampleThoughtContent`，不保留兼容实现。
- 复用 MarkdownRenderer、ScrollBox、Button 和 lucide-react；没有公开思考文本时不显示面板，不生成摘要或假思考。
- 执行中显示内容；进入明确的最终回答阶段自动折叠一次，之后手动展开不被增量或 answering → completed 覆盖。失败/停止保留内容与阅读方式。
- 流式更新仅在用户仍跟随底部时滚动；上翻后保留阅读位置。回到最新入口在工具栏固定占位，不挤动内容或遮挡操作。

## 实施顺序与原因

1. 新增 ThinkingPanel：公开 content、streaming、phase、height、className、style；阶段复用 UI 展示类型，内容与业务协议解耦。新一轮由调用方使用 key 重建，避免猜测任务边界。
2. 保持同一内容 DOM，使用固定工具栏与内部滚动区；分离「面板折叠」和「全部展开」，避免改变阅读方式时重挂载 Markdown。
3. 调整 C03 内容容器允许自然增高，替换临时示例；默认左右高度不变，完整展开仅增加右侧高度。
4. 注册独立入口、调试台状态和公开参数；覆盖短内容、长内容、流式、最终回答、完成、停止、失败与空内容。
5. 运行类型检查、UI 目录覆盖、构建与浏览器检查；检查跟随/上翻、展开/收起、阶段快速切换、空内容、键盘、窄屏及布局稳定，记录实际结果。

## 规则核对口径

- 按根 AGENTS.md 八条规则验收；无 `.cursor/rules`、无可用 `.mdc`，未找到约定 space 上下文。
- 用户明确要求的完整展开与最终回答折叠可以改变高度；流式反馈、回到底部入口和失败/停止不改变默认布局。
- 无新增业务接口，不触发接口试验台交付；现有未提交的其他功能修改不在本轮范围。
