# C07 用户消息气泡验收

日期：2026-11-20。范围：`packages/ui` 的 UserMessageBubble 及组件调试台。后续按用户确认补充共享文件卡片和真实图片缩略图，不包含聊天页面替换。附件实现与验证详见 [附件验收](attachment-validation.md)。

## 实现与公开参数

- `text: string`：用户原文，直接作为 React 文本节点展示，不解析 Markdown/HTML，不 trim，不截断。
- `attachments?: ReactNode`：附件插槽；文件展示、打开或预览由调用方组合。插槽在文字气泡上方，支持换行。
- `className / style`：根元素样式；默认右侧对齐、自适应内容宽度，最大宽度为父级 85% 与 44rem 中较小者。
- 多行、空行、空格和制表符保留，长路径与连续英文允许换行。正文自然撑高，默认不内部滚动。
- 只有附件时不渲染文字气泡，不补造「已发送附件」等正文；文本为空字符串且无附件时不占位。非空空白字符串仍按原文展示。
- 调试台提供短文本、多行、长文本、字面内容、文字与附件、仅附件、空内容七个样例；可编辑文本、切换附件插槽及调整尺寸。
- 附件样例使用 AttachmentCard 与真实 PNG 缩略图，复用 TaskComposer 的图标、颜色、大小展示及缩略图尺寸；图片可实际预览，文件通过回调交给调用方打开。

## 八条规则核对

1. 只实现 C07 的原文与附件布局，不增加编辑、复制、重发或消息状态能力。
2. 组件只接收 props，不请求接口，不依赖后端或页面状态。
3. 原文保真、空消息与附件边界已有注释。
4. 按现有 C07 明确范围实现，组件与聊天页面接入分开交付。
5. 新增组件，不替换聊天页面已有实现；后续替换按项目规则确认。
6. 中性背景表达气泡，无完整边框嵌套、描边加阴影或彩色边框。
7. 组件和样式位于 packages/ui，调试台仅演示组件公开参数与附件插槽。
8. 组件没有独立状态提示；附件回调反馈由调试台固定区域承载，点击前后气泡位置及尺寸相同。

本轮无公开业务接口变更，接口试验台要求不适用。文件卡片及真实缩略图已补充；完整 C09 图片组与真实聊天接入仍为后续任务。
