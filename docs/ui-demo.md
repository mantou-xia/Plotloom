# 组件库调试台

## 启动与使用

在仓库根目录执行 `pnpm.cmd ui`，访问 `http://127.0.0.1:4320`。无需启动后端。

- 左侧选择通用组件，右侧「初始样例」加载一组参数；中央直接渲染 `packages/ui` 的真实组件，不展示完整业务页面。
- 侧栏支持组件英文名、标识、中文说明、分类和样例名称搜索，不区分英文大小写，多个关键词按同时匹配过滤；无结果时显示提示和数量。点击清空按钮或在搜索框按 Esc 恢复完整目录。
- 分类默认展开，可点击或用 Enter/空格独立折叠。搜索时展开匹配分类，仍可手动收起；修改关键词重新展开匹配项，清空搜索恢复搜索前的分类状态。状态保留在当前调试会话，刷新后重置。筛选与折叠不重置当前预览。
- 侧栏搜索和结果数量固定可见，中间目录复用 ScrollBox 独立滚动，筛选前后滚动条占位保持一致。
- 「画布尺寸」作用于 iframe 的真实视口，支持拖动右下角与窄屏/中屏/宽屏快捷尺寸。宽度 240—2400px，高度 160—1600px；媒体查询随画布变化。
- 「组件尺寸」独立设置真实组件根元素宽高：自动使用组件默认尺寸、固定像素（1—2400px）、填满画布扣除四周 24px 留白后的可用空间。固定高度时内容可滚动，超过画布的组件可滚动查看。
- 数字按 Enter 或失焦提交，空值恢复原值，超范围值约束到可选范围；切换尺寸模式保留上次输入的像素值。
- 按组件提供实际可用属性：按钮文字、六种变体、三档尺寸、危险、加载、禁用及图标位置；布局内边距、间距和侧栏宽度；色点直径和间距。Button 总览固定展示全部能力，右侧只调节顶部「交互试用」按钮。ColorPicker 的 HEX/RGB 通过初始样例或面板自身格式控件调整。
- 配色支持六个主题预设及纯色面板（取色、HEX/RGB、色板、最近颜色）；宿主与预览同步，预览中的取色回调也会更新宿主。不写产品 localStorage。
- 直接悬停、按住鼠标、Tab 聚焦检查真实 CSS 状态；组件回调在预览下方显示。
- 「重置预览」恢复当前组件默认样例、画布与组件尺寸、属性及默认蓝色，并清空组件交互。
- 修改尺寸、属性和主题保留组件交互；切换组件/初始样例会恢复相应参数并重置交互。刷新调试台回到默认示例。

构建：`pnpm.cmd ui:build`。构建预览：`pnpm.cmd ui:preview`（同为 4320，先停止开发服务）。

## 2026-11-18 ScrollBox 无溢出时隐藏滚动提示

原实现固定开启原生滚动机制以保持占位，但悬停着色不检查溢出，导致 Windows 在不可滚动区域仍露出上下箭头。现统一检测允许方向的实际溢出，无溢出时保持滚动条透明；有溢出时才应用悬停、聚焦或始终显示规则。通过尺寸与内容观察同步更新，卸载时释放观察器及待执行动画帧，不改原生滚动机制与占位。

- Chromium 验证 GlobalLayout 的外层侧栏滚动容器、内层 Sidebar 和正文在未溢出时保持透明，悬停截图不再出现箭头。
- 纵向、横向和双向模式均验证空内容悬停/聚焦/始终显示不着色，增加内容后显示，键盘可滚动，清空后恢复透明；全过程 clientWidth/clientHeight 保持一致。
- 长侧栏实际溢出时仍显示滚动条。脚本与截图：`output/playwright/scroll-overflow-check.js`、`scroll-no-overflow.png`、`scroll-with-overflow.png`。未出现页面运行异常，未验证其他浏览器。
