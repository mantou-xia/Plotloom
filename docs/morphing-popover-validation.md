# MorphingPopover 提取验收

日期：2026-11-19

## 范围

用户确认第一步提取按钮到面板的形变外壳。新增公开入口 `@plotloom/ui/morphing-popover`，TaskComposer 的模型与权限菜单均通过此组件渲染；保留原版弹簧参数、尺寸测量、模糊、交错和关闭时序。未提取普通按钮、选项列表、滑块或发送状态组件。

通用组件仅接收开关、触发器、内容、尺寸与方向等 props。原版共享上下文移入该目录，以便菜单内容与触发器继续感知形变阶段；它们不包含业务状态。外部点击与焦点检查采用 composedPath 和所属根节点，兼容普通 DOM 与原输入框 Shadow DOM。

原引擎的本地维护变更已登记在 `original/source.json`，上游校验值仍保留，其余三个源文件保持不变。

## 七条规则核对

1. 仅提取已在模型/权限两处复用的形变外壳，未建设额外框架。
2. 无应用状态、后端实现和网络请求依赖。
3. 尺寸测量、原版动画保留原因、动态重算和清理职责均有注释。
4. 范围按用户“可以”的明确确认实施，无未决需求冲突。
5. 本次是已确认的代码组织提取，原调用行为保留，旧外壳实现已移除。
6. 独立组件无边框叠加阴影；原输入框按此前用户明确要求保留原版视觉，不改 AGENTS.md。
7. 组件、样式和示例维护于 packages/ui，调试台展示通用内容及有效参数，没有应用业务页面依赖。

没有新增或修改公开业务接口，接口试验台登记要求不适用。

## 调试台模板展示修正

用户进一步明确用途为“按钮变成任意面板的形变容器”，用作后续对话框工具按钮的统一模板。之前切换样例会重新挂载，且所有样例初始化为关闭，导致方向与对齐虽已传入却不可见。本次只调整示例和说明，不改变通用容器或现有模型/权限菜单的接口。

- 除独立的“收起状态”外，样例初始化为展开；保留真实按钮点击，并提供明确的预览展开/收起控制。
- 增加自定义面板内容样例，展示说明、分栏和按钮可作为 children 组合。
- 预览内展示组合步骤与可复制代码，代码跟随当前内容类型、方向、对齐、减少动画和面板宽度更新。
- 浏览器逐项切换五种展开样例，不点击触发器即检查面板和锚点；验证收起样例连续形变、Escape、自定义回调、预览控制、320px 宽度、剪贴板代码和 375px 窄屏。全部通过，无页面异常。
- `pnpm.cmd --filter @plotloom/ui typecheck`、`pnpm.cmd test:ui`（20 项）与 `pnpm.cmd ui:build` 通过。首次构建曾被工作区表单 RadioGroup 的类型错误阻塞，未修改该文件；后续工作区更新后重跑构建通过。
- 验证产物：`output/playwright/verify-morph-template.cjs`、`morph-template-report.json`、`morph-template-custom.png`。截图已检查。七条规则继续满足；新增内容均为调试样例，未扩展业务或后端接口。

## 选项切换文字跳变修正

- 用户明确反馈“简洁／详细”等选项切换时文字跳变。逐帧复现确认：收回弹簧短暂小于按钮自然宽度，触发器的 `max-width: 100%` 使标签换行，排版高度由 32px 变为 48px，结束后恢复 32px。
- 形变期间解除触发器对动画外壳的最大宽度依赖，保持自然内容宽度；结束后恢复原约束。保留原版弹簧与缩放参数，不通过禁用回弹掩盖问题。
- 同时修正默认展开在 StrictMode effect 重放时被当作再次打开的问题，避免已显示的选项重新执行 y=6 的入场动画。真正点击打开仍有原版动画。
- 浏览器逐帧验证“简洁／详细／列表／表格”选择后触发器排版高度始终为 32px；四种初始展开样例的文字位置及透明度稳定。原 TaskComposer 完整回归通过，调试台构建和 20 项 UI 测试通过，diff 检查通过。
- 本次仅修正通用容器动画生命周期与尺寸约束，公开契约不变；七条规则继续满足，无业务接口变更。
