# Toast 交付验证

日期：2026-11-19。

## 范围

用户确认新建业务对象、删除、保存等功能操作可使用 Toast；后台读取成功及普通导航静默。创建对话、发送消息和停止生成仅在失败时弹 Toast，处理中、生成完成及正常停止由聊天界面反馈。保留加载、空态、生成/停止状态及重试入口。新增组件与调度工具位于 packages/ui，HTTP 与业务反馈包装位于 apps/web/src/utils；无后端协议变更。

## 已验证

- `pnpm typecheck`、`pnpm ui:build`、`pnpm web:build` 通过；`pnpm test:ui` 执行时 19 项全部通过（含 6 项新增 Toast 测试），`git diff --check` 通过。
- UI 状态测试：重复提示合并及计数、独立异步任务、FIFO、退出占位、取消等待消息、成功原位更新并返回原结果、同步/异步失败继续抛出、AbortError 静默取消、手动关闭后不复现、实例隔离和取消订阅。
- 组件调试台浏览器：同时产生 6 条时只显示 3 条，后 3 条补位后才开始计时；重复 5 次只有一条并显示次数；异步成功/失败保留同一 DOM 节点；悬停与键盘聚焦暂停、离开恢复；退出阶段保留节点，180ms 后移除；减少动态效果时 transition 为 0s。
- 首轮产品浏览器验证使用公开 HTTP/SSE 模拟响应；聊天操作提示范围已按后续确认调整为仅失败提示，后续复验结果见下方。
- 范围调整复验：产品类型检查及构建通过，20 项 UI 测试通过。浏览器模拟响应确认创建、发送、停止的处理中与成功均无 Toast；创建失败、发送 HTTP 失败、流式 failed、停止失败均保留错误 Toast，页面已停止状态正常显示。
- 主题色保存成功反馈、模拟 localStorage 写入失败反馈；原生自定义颜色模态弹窗内提示可见、可聚焦关闭，弹窗关闭恢复全局视口。
- 当前本机后端 4317 未运行，已验证真实连接失败使用 Toast。成功/业务失败/流式停止为浏览器模拟验证，不等同真实模型后端联调。

## 规范核对

1. 仅实现已确认反馈需求；不全局拦截按钮或 fetch。
2. UI/调度不访问后端内部实现；业务通过公开 HTTP/SSE。
3. 关键调度、计时、异步结果、模态挂载与业务操作均有职责注释。
4. 范围已由用户明确确认。
5. 用户已同意直接替换临时反馈；移除相关旧文案及样式。
6. Toast 用白底、留白和无边框阴影；无彩色边框、嵌套完整边框或 border/outline 叠加。
7. 通用组件在 packages/ui，业务包装在应用 utils；调试台展示组件与参数，不展示完整业务页面。

公开业务接口未变更，不涉及接口试验台目录修改。
