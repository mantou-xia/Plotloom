# 平台普通聊天验收

2026-11-26。首页和侧栏「新聊天」打开普通对话，配置可用模型后可直接发送。普通聊天沿用平台人设，历史显示在「最近」。项目和小说分组仍各自创建有归属的聊天。

- 独立 API 和试验台回归 21 项通过。覆盖普通会话创建、首轮生成、人设注入、跨重启保存、项目工具及审批配置限制，以及保留项目接口原有校验。
- Playwright 用产品构建连接本机后端和模型协议替身，验证空项目首页直接发送、收到回复、最近列表出现该会话，以及从会话返回「新聊天」。
- 组件调试台从搜索打开「新聊天欢迎区」，验证普通、项目、小说状态、项目选择按钮及浅色、深色、跟随系统设置。
- 类型检查、产品和调试台构建、Git 差异检查通过。

后端复用既有普通会话入口，公开接口通过 `mode: "general"` 表达无工作区。前端延续原草稿、上传与发送流程，按归属启用文件和审批控件。欢迎区沿用主题变量与组件库，发送反馈保持原有占位。未替换项目和小说接口。使用方式见接口试验台「创建普通或项目会话」。
