# P7 自定义主题色验证

日期：2026-11-18。范围：浅色界面下自主选择强调色；一级页面 `PageLayout` 未新增样式，创作页面与深色模式不在本次范围。

本文记录初版验收。后续已按用户要求收为「六个预设圆点＋圆形添加按钮」，自定义颜色改为点击弹窗；当前使用方式和追加验收见 `docs/ui-demo.md`，以下实时预览及独立恢复默认按钮属于历史版本。

## 实现与使用

启动 `pnpm.cmd web`，点击侧栏「设置」：六个预设色、可视化取色器、HEX 输入、实时预览、恢复默认。颜色作用于按钮、选中状态、链接与焦点；边框仍为中性灰。

- `packages/ui/src/theme`：生成色阶及文字前景、统一主题变量与根组件。
- `packages/ui/src/button`、`color-picker`、`settings`：所有新增组件与样式。
- `apps/web/src/features/settings`：主题偏好状态与 localStorage 保存；存储键为 `plotloom.theme-color`，仅影响当前浏览器来源，不调用后端。
- `react-colorful` 5.8.1 提供取色交互，`@ant-design/colors` 8.0.1 提供色阶生成；通过包依赖使用，未复制 tweakcn 源码。

用户选择的主色保持不变；按钮各状态独立选择黑白文字。链接与选中区域采用能满足对比度的同色系深色，必要时回退黑色。黑色生成的最浅色阶仍可能偏暗，因此浅色选中背景在此时回退中性浅灰。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| `pnpm.cmd typecheck` | 通过 |
| `pnpm.cmd test:ui` | 2/2 通过：HEX 校验，以及 216 个 RGB 网格色加预设/灰色样本的状态与文字对比度检查 |
| `pnpm.cmd web:build` | 通过 |
| 生产预览 | 4320 临时端口检查设置入口、换色、刷新恢复、重置；无运行错误、控制台错误或 HTTP 失败 |

浏览器实测通过：

1. 选择预设后根主题及 localStorage 同步改变，刷新恢复所选颜色。
2. 输入六位 HEX 立即应用；三位 HEX 按 Enter 展开；非法输入保留错误提示且不修改当前主题或保存值。
3. Esc 撤销未完成草稿；从非法输入切换预设或恢复默认后草稿正确清空。
4. 可视化取色器鼠标拖动、色相滑块方向键均能修改主题；控件焦点可见。
5. 黑、白、黄色可以选择，按钮悬停时文字与背景保持可区分；自动化检查覆盖正常、悬停、按下、选中及链接的 4.5:1 文字对比度。
6. 损坏的已保存颜色回退默认；模拟写入失败时当前主题仍应用，界面明确提示未能保存。
7. 恢复默认后刷新仍为默认蓝色。
8. 1440×900、1024×768 桌面窗口无横向溢出；截图已人工查看。检查实际 DOM 未发现边框与阴影叠加。

截图位于临时输出 `output/playwright/theme-settings.png`、`output/playwright/theme-settings-1024.png`，不作为提交产物。

## 七条规则核对

1. 只实现已确认的换色、保存与恢复默认，没有扩展主题编辑平台或深色模式。
2. 组件仅通过 props/回调接收状态，不依赖后端；外观偏好使用浏览器存储。
3. 主题派生、HEX 提交及保存逻辑有职责和原因注释。
4. 按用户确认方案实施，一级页面样式继续留待讨论。
5. 在现有骨架上新增功能，没有删除或替换旧业务接口。
6. 取色器自带的边框与阴影组合已在封装内调整；所有组件遵守项目边框规范。
7. 组件和组件样式全部在 `packages/ui`，feature 只管理偏好，app 只做组合。

未新增或修改公开业务接口，本次不涉及接口目录登记；未重跑后端接口或真实模型测试。
