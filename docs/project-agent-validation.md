# 项目 Agent 与正式聊天接入验收

日期：2026-11-19。范围按用户确认：使用当前 TaskComposer 替换旧输入框，不保留旧版；暂不接小说工作区，完成通用项目中的文件与终端任务闭环。

## 交付能力

| 类别 | 正式页面已支持 |
| --- | --- |
| 项目会话 | 新聊天填写现存绝对目录，或复用最近项目；目录随会话保存，跨服务重启恢复。 |
| 项目任务 | Agent 读取、列举、搜索、创建和编辑文件，执行终端命令；Windows 使用 PowerShell。 |
| 对话与历史 | 流式正文、模型返回的可见思考、工具进度与结果、停止生成、历史重开与运行快照。 |
| 模型配置 | 已配置模型选择、按模型真实能力展示思考档位；配置失败恢复原值。 |
| 附件 | PNG/JPEG/WebP、UTF-8 TXT/Markdown，上传、未发送移除、纯附件/混合发送、历史按需预览。 |
| 技能 | 聊天启用技能，检查工具依赖，@ 或 / 选择本轮技能并发送真实 skillIds。 |
| 项目引用 | @ 关键词搜索当前项目相对路径，选中后随文字发送，由 Agent 工具读取。 |
| 上下文 | 用量与窗口展示、未知用量提示、自动压缩开关、手动压缩及取消。 |

项目工具直接执行，目录是默认工作位置，不是沙箱。权限审批三档、计划模式、持续目标模式和小说工作区前端未实现；对应演示入口在正式输入框中隐藏。PDF/Word 等附件不在本轮范围。项目目录创建后固定，切换需新建聊天。技能完整管理目前使用试验台，正式技能页展示列表。

真实浏览器操作正式页面；除明确标注的错误注入外，均通过 Vite 代理访问真实后端与 Pi。测试文件位于临时项目，未修改用户业务文件。

- vision / plain 模型切换，前者显示真实推理档位，后者仅 off；模拟配置 PUT 422 后仍为原档位。模型复合 ID 中引号曾导致选择器异常，已使用 CSS.escape 修复并回归。
- TXT 纯附件发送、历史文本预览（HTML 按文本展示）；图片模型能力拒绝、损坏 PNG 拒绝、有效 PNG 上传及真实 DELETE 移除通过。
- 模拟消息 POST 422，未 accepted 时草稿保留；正常 accepted 后清空。
- @README 搜索选择及发送；技能启用后 / 菜单选择，实际请求携带目标 skillId。技能菜单使用名称展示，内部仍用唯一 ID。
- 自动压缩切换落后端；足量历史手动压缩返回 completed。另用暂停模型摘要响应的 fixture 点击停止，真实 compact/stop 返回 200，原 compact 请求返回 aborted。
- 生成等待期间点击停止，SSE 最终 aborted；重开读取历史。桌面和 768px 宽布局检查，无页面横向溢出。

## 七条规则核对

1. 不过度设计：仅增加会话项目归属、有限文件候选和当前组件协议适配，未建设项目管理框架或审批系统。
2. 前后端解耦：组件库只接收数据与回调；应用只调公开 HTTP/SSE；独立 API 测试和真实模型验收脱离前端可运行。
3. 关键注释：目录校验/候选扫描、项目工具边界、配置互斥、发送接收与完成分离、附件 ID 映射和消息转换均说明职责及原因。
4. 先澄清：项目文件修改与终端权限已取得用户明确确认，小说前端本轮暂缓。
5. 旧版处理：用户已明确不保留旧输入框；已替换并移除旧输入框逻辑/样式，无双版本兼容分支。
6. 边框层级：本轮新增页面与设置区用背景、间距分层，无新增彩色边框或嵌套完整边框；现有 TaskComposer 按用户要求保留原版视觉与动效，不改全局规则。
7. 组件归属：复用组件库 TaskComposer、表单、按钮与布局；项目创建、聊天协议、附件历史等一次性业务组合留在 apps/web。

接口交付：创建参数、会话摘要、项目文件搜索、项目工具和会话技能诊断均同步契约/目录；独立测试、目录覆盖与试验台真实触发已完成。
