# 分屏布局组件实施计划

用户确认将左右分屏能力实现为组件库的布局组件。本轮只交付通用布局与调试台，不接聊天页面或修改来源组件。

1. 在 `packages/ui` 新增 `SplitPaneLayout`，使用固定版本 `react-resizable-panels@4.24.1`，复用 Button 与 ScrollBox。
2. 公开主内容、右侧内容、标题/操作插槽、受控开关、初始宽度、宽度上下限与窄屏阈值。布局不保存业务数据或访问后端。
3. 桌面拖拽/键盘调宽，关闭后恢复上次宽度。两侧独立滚动，保留 DOM 和阅读位置。容器变窄时右侧改原生模态覆盖层，处理焦点、Esc 和关闭恢复。
4. 登记调试台，展示展开、收起、长内容、窄屏和空内容；所有交互通过公开参数驱动。
5. 类型检查、UI 目录覆盖测试、构建与真实浏览器验收；检查八条项目规则并记录结果。

层级约定（用户补充确认）：SplitPaneLayout 与 PageLayout 同级，页面根据需求二选一，不嵌套使用；本组件与 GlobalLayout 无依赖关系。开源库处理拖拽约束与键盘，应用决定内容和持久化。关闭和宽窄切换保持同一内容节点，避免丢失用户阅读状态。
