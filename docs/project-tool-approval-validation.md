# 项目工具权限与审批验收

日期：2026-11-20。范围：用户确认所有项目会话统一迁移，保留历史；首批交付受限文件工具及写入审批。

## 行为与边界

- 项目会话提供 `read`、`ls`、`find`、`grep`、`write`、`edit`。受限执行器只处理项目内的普通 UTF-8 文件，拒绝链接、带已知敏感名称的路径和应用数据目录。搜索按字面匹配。单文件上限 256 KiB，创建时父目录须存在。
- 写入使用本次待审批快照。获批后复核原文、目标及父目录身份，变化时拒绝执行。允许、拒绝、取消和过期决定记录到会话元数据；待审批记录保留在服务进程，刷新可查询，重启后不复用。整轮重试会产生新的审批。
- 项目聊天首批暂时停用终端、独立浏览器及网页抓取。2026-11-21 起，普通、项目和小说聊天均提供 `browser` 和 `web_fetch`。文件校验属于 Plotloom 的工具限制，针对主动并发改写文件系统的本地进程仍需 OS 层隔离。Windows PowerShell 执行隔离及产品级人机授权边界未在本阶段验收。

## 验收记录

- 命令 `pnpm.cmd test`、`pnpm.cmd test:demo` 与 `pnpm.cmd test:ui` 覆盖状态、文件读写和公开路由。项目测试使用真实文件系统和本机协议替身。
- Edge 组件调试台验证「允许一次」原位反馈及独立状态。正式聊天实测生成提出写入、刷新恢复待审批、批准后落盘。
- 接口试验台使用真实 HTTP/SSE 与隔离项目，实测允许、拒绝、重复决定返回 409，以及等待审批时停止。审批接口和事件已登记至 `packages/contracts/src/catalog.ts`。
- 组件和正式页截图位于 `output/playwright/tool-approval-card.png` 与 `output/playwright/tool-approval-chat.png`。浏览器验收使用确定性模型协议替身。

## 2026-11-21 输入区内嵌审批

- 有待批工具调用时，服务端返回 `status: running`、`activity: awaiting_approval`。详情、会话列表及上下文接口共享该活动状态。最后一项离开审批队列后，活动恢复生成，整轮结束后回到空闲。
- 聊天输入区原位显示审批卡。编辑器在等待时保持挂载和原有占位，屏蔽输入及辅助技术交互。Agent 活动区、对应工具节点和侧栏显示「待审批」，过程区保留已发生的步骤。
- Edge 实测接口试验台读取待审批快照和拒绝操作。正式页覆盖输入区位置不变、刷新恢复审批、允许后实际写入、拒绝和停止后恢复输入框。截图位于 `output/playwright/tool-approval-inline.png`。

## 2026-11-21 项目审批模式切换

- 项目输入框复用权限菜单，显示「需要审批」和「完全访问权限」。默认逐次审批，选择按会话保存。完全访问免项目内的文件写入审批，继续执行项目目录和文件访问校验。
- Edge 实测现有会话双向切换、刷新恢复以及新项目对话首轮真实写入。接口试验台实测 `GET` / `PUT /api/sessions/:id/config`；独立接口覆盖重启持久化、非法模式、忙碌时拒绝修改、免审批时拒绝越界和切回逐次审批。截图位于 `output/playwright/project-approval-modes.png`。

## 2026-11-21 Agent 文件对比验收

- 项目聊天使用「打开工作区 → 文件对比」。每次成功写入可独立展开，查看文件相对路径、新增和删除行数、修改前后行号、变更行及可展开的未改动上下文。
- 对比使用会话保存的写入前后内容。新建、覆盖和编辑均有记录，审批未通过、停止和无实际变化的写入不会新增记录。历史写入仅覆盖功能上线后的操作。本机进程若在文件提交和记录追加之间终止，可能缺失这一条对比。
- 独立接口覆盖同一文件多次写入、CRLF 行尾、跨聊天拒绝、小说会话拒绝、非法参数、后续人工修改及重启后恢复。试验台在隔离项目实际触发列表和单次差异查询，验证最近一次写入 ID 自动填入、真实内容返回及错误记录 404。
- Chromium 实测等待对比时控件位置稳定、红绿增删和行号正确、未改内容可折叠、刷新保留展开状态、切换聊天隔离。验收截图保存于 `output/playwright/agent-file-diff.png`。
- 类型检查、产品构建和接口试验台构建通过。全量接口测试 94 项、试验台测试 14 项、界面测试 29 项通过。

## 2026-11-21 单轮文件变更摘要验收

- 项目聊天在有成功写入的轮次底部展示通用 `FileChangeSummary` 组件。显示文件数、总增删与逐文件统计，默认列前三项。「查看变更」打开右侧「本轮文件对比」，沿用单次写入快照。
- 独立接口测试验证运行中隐藏本轮摘要，无变化和拒绝写入时省略摘要，同一文件重复写入只计算净变化，停止前已保存的写入在结束后可见，重启后摘要一致。
- 浏览器使用隔离项目及模型协议替身，实测无修改时无卡片、四个文件折叠与展开、快速查看两轮各自的变更、刷新恢复，以及接口试验台检查会话详情的实际 `fileChanges` 响应。截图保存于 `output/playwright/agent-file-change-summary.png`。
- 类型检查、产品及试验台构建通过。全量接口测试 94 项、试验台测试 15 项、界面测试 29 项通过。
- 文件摘要布局复验：卡片处于正文与消息操作之间，成功轮次省去空状态行。Chromium 在 390 像素宽度下验证长目录优先省略、文件名保留可见。双层滚动区在短差异时占位均为 0 像素，增删底色贴齐右侧，短差异也按内容高度收紧，末行到容器底部实测 0 像素。长差异仍可在最大高度内双向滚动。截图保存于 `output/playwright/agent-file-change-summary-layout.png` 和 `output/playwright/agent-file-diff-flush.png`。
- 摘要交互复验：单文件显示文件名和增删统计，无列表。多文件行可用鼠标或键盘展开对应文件的写入记录，「查看变更」每次进入本轮全部收起状态。验证同路径多次写入、重复切换入口及工作区不显示修改时间。单文件截图保存于 `output/playwright/agent-single-file-summary.png`。

## 2026-11-22 小说目录、文件审批与对比

- 小说管理页和聊天文稿目录共用文稿列表项，显示标题、扩展名、修改日期与两行摘要。正文、角色阶段和大纲都支持右键定位，正文另有回收站操作。Chrome 实测右键未选中章节、取消、确认删除和刷新后的选中状态。Windows 独立接口测试验证同名外部改稿触发 409、回收后定稿仍可读，以及非正文和越界路径校验。
- 项目和小说会话共用受目录约束的文件工具、审批决定协议和成功写入快照，小说通过原工作区 ID 解析根目录。小说专有的交稿、角色卡和世界观确认使用 ToolApprovalCard。普通选择题保留自填与跳过；分章创作沿用该轮可见资料和候选审阅规则。
- 文件对比只展示已提交修改。暂存、拒绝与未采纳候选不会产生写入记录。工作台采纳后，按候选来源归入原聊天轮次。已有旧候选若缺少轮次关联，采纳后的写入保存在来源会话的文件清单内。
- 正式页面用隔离模型完成小说审批、刷新和打开逐行差异。长预览在 1280×900、390×740 两种视口下的卡片高度分别为 585、481 像素；滚动预览不移动审批按钮。正文编辑、自动保存、角色阶段顺序和世界观读写回归通过。
- 接口试验台通过实际 HTTP 请求读取目录摘要、向资源管理器发送定位请求、回收临时章节，分别核对成功响应、未知文稿 404 和版本冲突 409。通过小说会话提交文件搜索、写入列表和单次差异请求，响应字段检查均通过。上述三个目录接口为普通 JSON 操作；聊天停止沿用现有停止接口。
- 窄屏聊天工作区使用原生模态面板，右键菜单挂载在同一面板中。440 像素宽度下实测右键章节、取消回收、返回编辑器；390 像素宽度下滚动普通长题干后可直接选择并发送答案。
- 全仓类型检查通过，试验台及 UI 自动测试 50 项通过。串行运行独立接口测试 112 项，其中 111 项通过；供应商测试在删除其临时目录时偶发 ENOTEMPTY，该文件单独复跑 2 项均通过。
