# 聊天交付产物验收

Agent 回复中的会话相对文件链接可在右侧工作区打开。相同路径每轮只生成一张 AttachmentCard，显示在该轮的文件对比上方。Shift＋左键将文件交给 Windows 默认应用。普通点击支持 UTF-8 Markdown 和常见光栅图片预览，其他格式在工作区显示不支持提示。

## 接口与验证

- `POST /api/sessions/:id/deliverable` 已登记到接口试验台。传入会话相对路径和 `preview` 或 `open`，服务端从会话解析项目或小说目录，并限制在该目录的普通文件范围内。
- 独立 HTTP 测试覆盖项目 Markdown、小说 `正文章节/第四章.md`、图片、不支持预览、目标不存在、目录越界及拒绝从外部启动脚本。
- 浏览器验收覆盖正文链接、重复路径合并、卡片位置、刷新恢复、键盘打开、预览快速切换及正文链接和卡片的 Shift＋左键。试验台实际发送预览、外部打开及不存在文件的请求，得到对应的 200 或 404 响应。
- 自动验收用测试宿主检查后端传入的文件路径可访问，Windows 默认应用的实际启动留待桌面实测。
- 交付产物相关验证已通过。全量类型检查及既有项目读取回归受工作区并行修改的 `project-tools.ts` 作用域错误影响。

浏览器验收脚本为 `tests/ui/deliverable-browser.js`。以 `tests/ui/basic-agent-server.ts` 启动端口 4432 的隔离后端，产品页面和试验台分别在 4463 和 4464 代理该后端，再通过 Playwright CLI 运行脚本。
