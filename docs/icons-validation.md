# Lucide 图标替换验收（2026-11-18）

## 范围

- 保留并验证工作区已有的 `lucide-react@1.74.0`、主题设置与颜色选择器 SVG 图标。
- 在 `packages/ui` 安装包管理器发布时长策略允许的 `lucide@1.73.0`，通过 `@plotloom/ui/icons/dom` 为原生接口试验台提供 SVG；未放宽依赖安装策略。
- 替换试验台会话标识、信息提示、发送箭头、流程箭头、空响应和检查成功/失败的字符图标。请求结束后的按钮重绘也使用 SVG。
- 使用约定见 `packages/ui/README.md`：先查 Lucide 目录与实际导出名、按需导入、统一描边和语义、不用字符冒充图标。

- `pnpm.cmd web:build`、`pnpm.cmd ui:build`、`pnpm.cmd demo:build`：通过。
- 浏览器：主题预设勾选随选项移动、自定义按钮打开弹窗、预设与最近颜色勾选、关闭按钮和 Esc 均通过；图标有真实 SVG 且装饰图标不重复参与辅助技术朗读。
- 浏览器：接口试验台静态图标、成功与失败检查状态、发送按钮重绘、390px 窄屏无横向溢出均通过。状态检查使用浏览器拦截的 200/503 响应，仅验证前端展示，不代表真实接口验收；503 网络错误日志为主动模拟的预期结果。
- 已查看主题弹窗与试验台截图，临时验证脚本及截图位于 `output/playwright/check-lucide-*.js`、`output/playwright/lucide-*.png`。
- 源码检索未发现剩余的勾选、箭头、emoji 等字符图标；正常文本、品牌字样和尺寸乘号保留。

## 七条规则核对

1. 仅替换当前图标，原生入口只登记实际使用项。
2. 无后端实现依赖，接口试验台仍通过公开 HTTP 协议调用后端。
3. 原生 SVG 入口已说明职责、静态按需导入及辅助技术约束。
4. 安装和替换范围已获用户明确授权。
5. 仅替换已授权的字符图标，既有业务接口与行为保留。
6. 未增加边框、阴影或聚焦层级；仅调整 SVG 对齐。
7. 图标依赖与 SVG 生成入口均位于 `packages/ui`，原生试验台负责调用和页面组合。

没有新增或修改公开业务接口，因此未调整接口目录或执行后端/真实模型测试。
