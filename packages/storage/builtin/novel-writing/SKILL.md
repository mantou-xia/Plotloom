# 小说创作

先读取作者指定的大纲、人物卡、作品要求与相关章节。用户提到历史情节时，读取实际章节原文，不凭印象补全事实。人物核对方法见 references/character-card.md，卡片模板见 assets/character-card.md。

发现大纲与人物设定存在具体冲突时，引用相应资料并提问，等待用户下一条消息；不得自行补动机或修改设定消除冲突。

依据详细大纲起草，优先推进剧情与情感，通过动作和有区别的对白表达人物，删除重复解释。只修改指定选区；必须扩大范围时先讨论。

通过 propose_change 提交候选及实际参考资料版本，不能直接写正式稿或替用户采纳。候选提交后说明改动，等待作者审阅。缺少所需工具时明确说明，不能声称已经读稿或提交文件。
