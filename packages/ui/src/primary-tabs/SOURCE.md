# 一级 Tab 样式来源

参考：https://uiverse.io/zanina-yassine/curly-shrimp-52

源码：https://github.com/uiverse-io/galaxy/blob/main/Buttons/zanina-yassine_curly-shrimp-52.html

保留灰底、9px/7px 圆角、130×28px 选项基准和 0.2 秒白色滑块动效。按项目规则去掉滑块描边；使用已有 Base UI Tabs 提供语义、面板关联、键盘与尺寸测量，移除原例固定三项的 radio 定位。
